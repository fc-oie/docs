NBRJOBS

Below are the column names for NBRJOBS.

Columns for NBRJOBS
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
NBRJOBS_PIDM NUMBER 22 PIDM: Internal identification number of the employee.
NBRJOBS_POSN VARCHAR2 24 POSITION: Position Number.
NBRJOBS_SUFF VARCHAR2 8 SUFFIX: Suffix of the job.
NBRJOBS_EFFECTIVE_DATE DATE 7 EFFECTIVE DATE: Date that the Job Assignment record becomes effective.
NBRJOBS_STATUS VARCHAR2 4 STATUS: Status of the job. Valid values are A = Active, B = Leave without pay with benefits, L = Leave without pay without benefits, F = Leave with full pay and benefits, P = Leave with partial pay and benefits
, T = Terminated.
NBRJOBS_DESC VARCHAR2 480 DESCRIPTION: Description of the job. Defaults from the Position Title if left blank.
NBRJOBS_ECLS_CODE VARCHAR2 8 EMPLOYEE CLASSIFICATION CODE: The employee class attached to the job, based on the Employee Class entered on the Position Form (NBAPOSN).
NBRJOBS_PICT_CODE VARCHAR2 8 PAY ID CODE: The Pay ID attached to the job.
NBRJOBS_COAS_CODE_TS VARCHAR2 4 TIME SHEET CHART OF ACCOUNTS CODE: Valued only if Banner Finance is installed.
NBRJOBS_ORGN_CODE_TS VARCHAR2 24 TIME SHEET ORGANIZATION: Organization where time sheet is sent for this job.
NBRJOBS_SAL_TABLE VARCHAR2 8 SALARY TABLE: The Salary Table attached to the job. Defaults from the Salary/Rate Rule Form (NTRSALA) via the Position Form (NBAPOSN).
NBRJOBS_SAL_GRADE VARCHAR2 20 SALARY GRADE: The Salary Grade attached to the job. Defaults from the Salary/Rate Rule Form (NTRSALA) via the Position Form (NBAPOSN).
NBRJOBS_SAL_STEP NUMBER 22 SALARY STEP: The Salary Step attached to the job. Defaults from the Salary/Rate Rule Form (NTRSALA) or can be entered online.
NBRJOBS_APPT_PCT NUMBER 22 APPOINTMENT PERCENTAGE: The Appointment percent attached to the Job. Used to establish the percentage of full time appointment for an employee in a position. The value defaults from the position record, but t
he user may change at the job level. The appointment percent cannot exceed 100.
NBRJOBS_FTE NUMBER 22 FULL TIME EQUIVALENCY: The full time percentage attached to the job. Defaults to 1.
NBRJOBS_HRS_DAY NUMBER 22 HOURS PER DAY: The hours attached to the job that are normally worked in a day.
NBRJOBS_HRS_PAY NUMBER 22 HOURS PER PAY: The hours attached to the job that are normally worked in a pay period.
NBRJOBS_SHIFT VARCHAR2 4 SHIFT: The shift attached to the job.
NBRJOBS_REG_RATE NUMBER 22 REGULAR RATE: The regular rate attached to the job. If this field is entered or defaulted from the Salary/Rate Rule Form, the Assign Salary is system calculated and vice versa.
NBRJOBS_ASSGN_SALARY NUMBER 22 ASSIGNMENT SALARY: The salary to be paid each pay period. If the Assignment Salary is entered, the Annual Salary is calculated based on the factor and vice versa.
NBRJOBS_FACTOR NUMBER 22 FACTOR: The number of pays per calendar year.
NBRJOBS_ANN_SALARY NUMBER 22 ANNUAL SALARY: The annual salary attached to the job based on the calendar year. If the Annual Salary is entered, the Assignment Salary is system calculated based the factor and vice versa.
NBRJOBS_PER_PAY_SALARY NUMBER 22 PER PAY SALARY: Used for deferred pay calculations.
NBRJOBS_PAYS NUMBER 22 PAYS: Used for deferred pay calculations.
NBRJOBS_PER_PAY_DEFER_AMT NUMBER 22 PER PAY DEFERRED AMOUNT: The amount deferred each pay period for deferred pay calculation.
NBRJOBS_ACTIVITY_DATE DATE 7 Date of last activity (insert or update) on the record.
NBRJOBS_JCRE_CODE VARCHAR2 20 CHANGE REASON CODE: Associates the reason for the change with the job detail record.
NBRJOBS_SGRP_CODE VARCHAR2 24 SALARY GROUP CODE: The Salary Group Code attached to the job.
NBRJOBS_EMPR_CODE VARCHAR2 16 EMPLOYER CODE: The Employer Identification code attached to the job.
NBRJOBS_LGCD_CODE VARCHAR2 16 LONGEVITY CODE: Longevity code attached to the job.
NBRJOBS_LOCN_CODE VARCHAR2 24 LOCATION CODE: EEO location attached to the job.
NBRJOBS_SCHL_CODE VARCHAR2 24 SCHOOL CODE: EEO school attached to the job.
NBRJOBS_SUPERVISOR_PIDM NUMBER 22 SUPERVISOR PIDM: Internal identification number of the supervisor attached to the job.
NBRJOBS_SUPERVISOR_POSN VARCHAR2 24 SUPERVISOR POSN: The position number of the supervisor attached to the job.
NBRJOBS_SUPERVISOR_SUFF VARCHAR2 8 SUPERVISOR SUFFIX: Suffix attached to the supervisor’s position.
NBRJOBS_WKCP_CODE VARCHAR2 16 WORKER COMPENSATION CODE: Workers’ Compensation Classification Code attached to the job.
NBRJOBS_JBLN_CODE VARCHAR2 24 JOB LOCATION CODE: Job Location Code attached to the job.
NBRJOBS_PERS_CHG_DATE DATE 7 PERSONNEL CHANGE DATE: Date the change was actually made as opposed to the effective date which is for payroll purposes.
NBRJOBS_PCAT_CODE VARCHAR2 16 PREMIUM PAY CODE: Generates premium pay attached to the job.
NBRJOBS_DFPR_CODE VARCHAR2 16 DEFER PAY CODE: The defer pay schedule attached to the job. Defaults from PTRDFPR.
NBRJOBS_ENCUMBRANCE_HRS NUMBER 22 ENCUMBRANCE HOURS: Hours used to calculate the encumbrance amount for this job in the active fiscal year.
NBRJOBS_CONTRACT_NO VARCHAR2 32 JOB CONTRACT NUMBER: Job contract number attached to the job.
NBRJOBS_STRS_ASSN_CODE VARCHAR2 8 STRS ASSIGNMENT CODE: STRS Assignment Code attached to the job. Valid values are STRS mandated.
NBRJOBS_STRS_PAY_CODE VARCHAR2 8 STRS PAY CODE: STRS Pay Code for the employee attached to the job. The value selected determines how the employee’s salary will be reported to STRS administration on the monthly F-496 report.
NBRJOBS_PERS_PAY_CODE VARCHAR2 8 PERS PAY CODE: PERS Pay Code for the employee attached to the job. The value selected determines how the employee’s salary will be reported to PERS administration on the PERS Monthly Contribution Report
.
NBRJOBS_TIME_ENTRY_METHOD VARCHAR2 4 TIME ENTRY METHOD: Time Entry Method attached to the job. Valid values are P = Payroll, W = Web, D = Departmental, T = Third Party.
NBRJOBS_TIME_ENTRY_TYPE VARCHAR2 4 TIME ENTRY TYPE: Time Entry Type attached to the job. It represents the structure of how time will be entered over the Web or on the Electronic Approvals of Time Entry Form (PHATIME). Valid values are
T = Time Sheet, E = Exception Time Only, N = None.
NBRJOBS_TIME_IN_OUT_IND VARCHAR2 4 TIME IN AND OUT INDICATOR: Time In/Out Indicator attached to the job. Valiod values are Y = Yes and N = No. If Y, this employee must enter time in and out information on the Web or have it entered by a
department administrator on the Electronic Approvals of Time Entry Form (PHATIME). Time In and out must be entered for all earn codes that require hours entry. Time in and out will not be entered for earn codes that require units entry.
NBRJOBS_LCAT_CODE VARCHAR2 8 LEAVE CATEGORY CODE: A code which identifies a group of leave types. It is used when the Leave by Job Method has been selected for leave processing.
NBRJOBS_LEAV_REPT_METHOD VARCHAR2 4 LEAVE REPORT ENTRY METHOD: Leave Report Method Attached to the job. Valid values are P = None, W = Leave Report on the Web, D = Departmental Leave Report, T = Third Party Leave Report.
NBRJOBS_PICT_CODE_LEAV_REPT VARCHAR2 8 LEAVE REPORT PAY ID: The Leave Report Pay ID attached to the job and associated with a leave report or leave request.
NBRJOBS_USER_ID VARCHAR2 120 USER ID: The Oracle ID of the user who changed the record.
NBRJOBS_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: Source system that created or updated the row.
NBRJOBS_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key
NBRJOBS_VERSION NUMBER 22 VERSION: Optimistic lock token.
NBRJOBS_VPDI_CODE VARCHAR2 24 VPDI CODE: Multi-entity processing code.
NBRJOBS_PERS_PAY_RATE_OVER NUMBER 22 CALPERS PAY RATE: Pay rate reported to CalPERS where the derived pay rate must be changed for proper reporting.
NBRJOBS_PERS_SPECIAL_ONLY_IND VARCHAR2 4 PERS SPECIAL COMPENSATION ONLY: Indicates this job only includes special compensation earnings and no regular earnings. Special compensation will be reported under the matching/primary PERS XML payroll record.
NBRJOBS_CSST_CODE VARCHAR2 16 CALSTRS SERVICE TYPE CODE: California State Teachers Retirement System Service Type Code. Required for CalSTRS Defined Benefit Reporting for both members (DB1) and non-members (DB2).
NBRJOBS_CSTB_CODE VARCHAR2 16 CALSTRS TIME BASE CODE: California State Teachers Retirement System Time Base Code. Basis of employment associated with the contribution line.
NBRJOBS_CSPP_CODE VARCHAR2 16 CALSTRS EXPECTED PAY PERIODS CODE: Four digit California State Teachers Retirement System Expected Pay Periods Code used in Defined Benefit Reporting for Defined Benefit Members (DB1) or Defined Benefit Non-members (DB2).
NBRJOBS_STRS_FT_BASE_HRS NUMBER 22 CALSTRS FULL TIME BASE HOURS: The number of hours required in a school term for full-time. Required for reporting California State Teachers Retirement System Defined Benefit Non-member (DB2) employees performing creditable service.
NBRJOBS_STRS_HRS_DAY NUMBER 22 CALSTRS WORK HOURS PER DAY: The number of hours required per day in a complete workday for full-time.
NBRJOBS_SCLS_CODE VARCHAR2 8 CALSTRS CLASSIFICATION CODE: Code identifies classification used in CalSTRS monthly and supplemental reports of retirement contributions.
NBRJOBS_STIN_CODE VARCHAR2 4 CALSTRS AB1586 CODE: Code indicates whether an employee has been marked in CalSTRS system as eligible for recalculation of benefits.
NBRJOBS_PERS_APPT_ID VARCHAR2 40 CALPERS APPOINTMENT ID: 10-digit CalPERS ID for this employee which indicates their association with this employer by CalPERS Member Category.
NBRJOBS_PERS_PAY_RATE_TYPE VARCHAR2 12 CALPERS PAY RATE TYPE: CalPERS Pay Rate Type identifies hourly, daily or monthly pay. HRY-Hourly, DLY-Daily, MTY-Monthly.
NBRJOBS_PERS_SCHED_DAYS NUMBER 22 CALPERS SCHEDULED DAYS: Number of days per week considered full time if the Pay Rate Type is Daily.
NBRJOBS_SCLS_BASE_HRS NUMBER 22 CLASSIFICATION BASE HOURS: Minimum base hours associated to a classification code.
NBRJOBS_PERS_SCHED_HRS_WEEK NUMBER 22 NA
NBRJOBS_GUID VARCHAR2 144 GUID: Global Unique Identifier to uniquely identify the record of a resource for integration.
NBRJOBS_SUPERVISOR_GUID VARCHAR2 144 SUPERVISOR GUID: Global Unique Identifier to uniquely identify the record of a resource for integration.
