Overview

This section documents variables used for reporting and analysis. Definitions are authoritative; SQL examples are provided for reference only.

Variables

Gender

Type: Derived
Source Tables: SPBPERS
Source Fields: SPBPERS_GNDR_CODE; SPBPERS_SEX

Definition

Prioritizes self-reported gender identity when available and falls back to sex when no explicit gender identity is provided.

Classification Rules

Priority Condition → Value
1 Gender identity indicates non-binary -> Non-Binary
2 Gender identity indicates transgender -> Transgender
3 Sex = Male and no overriding identity -> Male
4 Sex = Female and no overriding identity -> Female
5 Insufficient or ambiguous data -> Unknown

Data Quality Notes

Older records may have NULL gender identity values. Sex codes X or N are treated as non-informative.

Optional SQL (Reference Only) 

CASE 
  WHEN s.spbpers_gndr_code LIKE '%B%' THEN '1' ELSE '0'
END AS "Non_Binary",

CASE 
  WHEN s.spbpers_gndr_code LIKE '%1%' THEN '1' ELSE '0'
END AS "Transgender",

CASE 
  WHEN s.spbpers_sex = 'M'
       AND s.spbpers_gndr_code NOT LIKE '%B%'
       AND s.spbpers_gndr_code NOT LIKE '%1%'
  THEN '1' ELSE '0'
END AS "Male",

CASE 
  WHEN s.spbpers_sex = 'F'
       AND s.spbpers_gndr_code NOT LIKE '%B%'
       AND s.spbpers_gndr_code NOT LIKE '%1%'
  THEN '1' ELSE '0'
END AS "Female",

CASE
  WHEN s.spbpers_sex NOT IN ('M','F')
       AND (s.spbpers_gndr_code IS NULL OR s.spbpers_gndr_code = '0')
  THEN '1' ELSE '0'
END AS "Unknown"

Retained

Type: Derived
Source Tables: SV_STUDENT_CURRENT_COURSES
Source Fields: COURSE_GRADE

Definition

Indicates whether a student remained enrolled through the end of the course.

Classification Rules

Priority Condition → Value
1 Course grade is not a withdrawal -> Retained 1
2 Course grade is a withdrawal -> Not Retained 0

Data Quality Notes

Withdrawals include W and EW.

Optional SQL (Reference Only) 

CASE
  WHEN c.course_grade NOT IN ('W', 'EW') THEN 1
  ELSE 0
END AS retained

Success

Type: Derived
Source Tables: SV_STUDENT_CURRENT_COURSES
Source Fields: COURSE_GRADE

Definition

Indicates whether a student successfully completed a course based on grade outcomes.

Classification Rules

Priority Condition → Value
1 Grade indicates successful completion -> Successful
2 Otherwise -> Not Successful

Data Quality Notes

Includes A, B, C, CR, P, INB, and INC.

Optional SQL (Reference Only) 

CASE
  WHEN c.course_grade IN ('A', 'B', 'C', 'CR', 'P', 'INB', 'INC') THEN 1
  ELSE 0
END AS success

Race_IPEDS

Type: Derived
Source Tables: SV_STUDENT_CURRENT_COURSES
Source Fields: PIDM

Definition

Assigns a single IPEDS race/ethnicity category using the institutional IPEDS ethnicity function.

Classification Rules

Priority Condition → Value
1 IPEDS ethnicity function returns a valid code -> Assigned IPEDS category
2 Otherwise -> Race/ethnicity unknown

Data Quality Notes

Derived from fz_get_student_ipeds_ethnicity; always produces a single IPEDS category.

Optional SQL (Reference Only) 

DECODE(
  fz_get_student_ipeds_ethnicity(c.pidm),
  'N', 'American Indian or Alaska Native',
  'A', 'Asian',
  'F', 'Filipino',
  'B', 'Black or African American',
  'H', 'Hispanic/Latina/o/x',
  'P', 'Native Hawaiian or Other Pacific Islander',
  'W', 'White',
  'T', 'Two or more races',
  'X', 'Race/ethnicity unknown'
) AS Race_IPEDS

Race_Asian

Type: Derived
Source Tables: SV_STUDENT_CURRENT_COURSES
Source Fields: ETHNICITY_CODE

Definition

Aggregates Banner ethnicity codes into Asian/PI versus Non-Asian/PI for equity-focused reporting.

Classification Rules

Priority Condition → Value
1 Ethnicity code in Asian or Pacific Islander code set -> Asian/PI 1
2 Ethnicity code not in code set -> Non-Asian/PI 0

Data Quality Notes

Based on local Banner ethnicity_code groupings; includes Asian and Pacific Islander codes.

Optional SQL (Reference Only) 

CASE WHEN c.ethnicity_code IN ('A.','AI','PH','PS','AC','AL','PG','AM','AK','PX','AV','AX','AJ','F.') THEN 'Asian/PI' ELSE 'Non-Asian/PI' END AS Race

Full_Time

Type: Derived
Source Tables: SV_STUDENT_CURRENT_COURSES
Source Fields: PIDM;TERM_CODE

Definition

Indicates whether a student is enrolled full time during the term.

Classification Rules

Priority Condition → Value
1 Enrolled units >= 12 -> Full-Time 1
2 Otherwise -> Part-Time 0

Data Quality Notes

Calculated using cumulative enrolled units.

Optional SQL (Reference Only) 

-- Full-Time (term enrollment units)
CASE
  WHEN TO_NUMBER(
         SUBSTR(
           f_split_fields(fw_student_enroll_data(c.pidm, c.term_code), 16),
           1,
           6
         ),
         '9999D99'
       ) >= 12
  THEN 1
  ELSE 0
END AS full_time

First_Generation

Type: Derived
Source Tables: SVBSGPD
Source Fields: SVBSGPD_GUARD_1_GEDL_CODE; SVBSGPD_GUARD_2_GEDL_CODE

Definition

Indicates whether a student is classified as first-generation based on parental education.

Classification Rules

Priority Condition → Value
1 Neither parent has a bachelor’s degree -> First-Generation (Yes)
2 Otherwise -> Not First-Generation (No)
3 Insufficient data -> Unknown

Data Quality Notes

Derived from most recent guardian education record.

Optional SQL (Reference Only) 

-- First_Gen
(SELECT first_gen
  FROM (
    SELECT
      SVBSGPD_PIDM,
      CASE
        WHEN SVBSGPD_GUARD_1_GEDL_CODE BETWEEN '1' AND '7'
         AND SVBSGPD_GUARD_2_GEDL_CODE BETWEEN '1' AND '7' THEN
          CASE
            WHEN GREATEST(SVBSGPD_GUARD_1_GEDL_CODE, SVBSGPD_GUARD_2_GEDL_CODE) < '4'
              THEN 'Yes'
            ELSE 'No'
          END
        WHEN SVBSGPD_GUARD_1_GEDL_CODE BETWEEN '1' AND '7' THEN
          CASE
            WHEN SVBSGPD_GUARD_1_GEDL_CODE < '4' THEN 'Yes'
            ELSE 'No'
          END
        WHEN SVBSGPD_GUARD_2_GEDL_CODE BETWEEN '1' AND '7' THEN
          CASE
            WHEN SVBSGPD_GUARD_2_GEDL_CODE < '4' THEN 'Yes'
            ELSE 'No'
          END
        WHEN SVBSGPD_GUARD_2_GEDL_CODE = 'Y' THEN 'Yes'
        ELSE 'X'
      END AS first_gen,
      ROW_NUMBER() OVER (
        PARTITION BY SVBSGPD_PIDM
        ORDER BY SVBSGPD_ACTIVITY_DATE DESC
      ) AS rn
    FROM SVBSGPD
    WHERE SVBSGPD_PIDM = c.pidm
  )
  WHERE rn = 1
) AS first_gen
