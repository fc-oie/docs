SVBREL8

Below are the column names for SVBREL8.

Columns for SVBREL8
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
SVBREL8_PIDM NUMBER 22 PIDM: PIDM related to the Student-ID.
SVBREL8_TXYR VARCHAR2 16 TAX YEAR: Tax Year (YYYY).
SVBREL8_SEQ_NO NUMBER 22 SEQUENCE NUMBER: Sequence Number of the Student Record in the Tax Year.
SVBREL8_STUD_NAME VARCHAR2 760 STUDENT NAME: Student Name as to be printed on the Releve 8 form.
SVBREL8_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key.
SVBREL8_VERSION NUMBER 22 VERSION: Optimistic lock token.
SVBREL8_ACTIVITY_DATE DATE 7 ACTIVITY DATE: Most recent date a record was created or updated.
SVBREL8_PRINT_DATE DATE 7 PRINT DATE: Date when the Releve 8 form was printed.
SVBREL8_PRINT_IND VARCHAR2 4 PRINT INDICATOR: Flag to indicate the printing status of a form. Values are W-Waiting to be printed, P-Printed.
SVBREL8_STATUS_CDE VARCHAR2 4 STATUS CODE: Status of the student information. Values are O-Original, A-Amended and C-Cancelled.
SVBREL8_FROM_DATE DATE 7 FROM DATE: Start Date of the Releve 8 data.
SVBREL8_TO_DATE DATE 7 TO DATE: End Date of the Releve 8 data.
SVBREL8_NUMB_SESS NUMBER 22 NUMBER SESSION: Number of Sessions the Student qualifies for. Max value is 2.
SVBREL8_AMOUNT NUMBER 22 AMOUNT: Amount of Releve 8 the Student qualifies for. Amounts set on SVATAXL form.
SVBREL8_HOLD_IND VARCHAR2 4 HOLD INDICATOR: Flag to indicate whether the Releve-8 data for a student is in hold or not for being printed/displayed. Values are Y-Hold for printing/displaying, NULL-Data can be printed/displayed.
SVBREL8_USER VARCHAR2 120 USER: Last User ID that modified the record.
SVBREL8_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: The latest source for the data contained in this record.
SVBREL8_CREATE_USER_ID VARCHAR2 120 CREATE USER ID: The logon ID of the user who created this record.
SVBREL8_CREATE_DATE DATE 7 CREATE DATE: The date this record was created.
SVBREL8_RLSQ_SEQ_NO VARCHAR2 64 RELEVE SEQUENCE NUMBER: Facsimile sequence number printed on a Releve 8 slip.
SVBREL8_BOXB_AMOUNT NUMBER 22 BOXB AMOUNT: Tuition or examination fees that include all mandatory fees paid by a student for education purposes.
SVBREL8_BOXC_AMOUNT NUMBER 22 BOXC AMOUNT: Total amount of charitable donations made by a student in a given tax year.
SVBREL8_XML_SEQ_NO VARCHAR2 64 XML SEQUENCE NUMBER: Releve 8 XML sequence number generated by a SVRRELX job.
SVBREL8_XML_FILE VARCHAR2 80 XML FILE: Releve 8 XML file name (AAPPPPPPSSS.xml ) with which the student Releve 8 slip associated.
SVBREL8_XML_VALI_STATUS VARCHAR2 4 XML VALIDATION STATUS: Status of the student information that was printed in a Releve 8 XML transmission file to indicate whether or not the information is validated by Revenue Quebec. Values:V - Valid, I - Invalid or rejected, F - File totally invalid
or rejected.The values will be populated via SVARXVS form.
SVBREL8_SIN VARCHAR2 60 SOCIAL INSURANCE NUMBER: This field stores student social insurance number to be printed on the RL-8 form.
SVBREL8_PERMANENT_CDE VARCHAR2 48 PERMANENT CODE: This field stores student permanent code to be printed on the RL-8 form.
SVBREL8_LAST_NAME VARCHAR2 240 LAST NAME: This field stores the last name of student to be printed on the RL-8 form.
SVBREL8_FIRST_NAME VARCHAR2 240 FIRST NAME: This field stores the first name of student be printed on the RL-8 form.
SVBREL8_MI VARCHAR2 240 MIDDLE NAME: This field stores the middle name of student to be printed as a middle initial on the RL-8 form.
SVBREL8_STREET_LINE1 VARCHAR2 300 ADDRESS LINE 1: This field stores the first line of the student address to be printed on the RL-8 form.
SVBREL8_STREET_LINE2 VARCHAR2 300 ADDRESS LINE 2: This field stores the second line of the student address to be printed on the RL-8 form.
SVBREL8_STREET_LINE3 VARCHAR2 300 ADDRESS LINE 3: This field stores the third line of the student address to be printed on the RL-8 form.
SVBREL8_STREET_LINE4 VARCHAR2 300 ADDRESS LINE 4: This field stores the fourth line of the student address to be printed on the RL-8 form.
SVBREL8_CITY VARCHAR2 200 CITY: This field stores the city of the student address to be printed on the RL-8 form.
SVBREL8_STAT_CODE VARCHAR2 12 STATE CODE: This field stores the state code of the student address to be printed on the RL-8 form.
SVBREL8_ZIP VARCHAR2 120 POSTAL CODE: This field stores the postal code (ZIP) of the student address to be printed on the RL-8 form.
SVBREL8_NATN_CODE VARCHAR2 20 NATION CODE: This field stores the nation code of the student address to be printed on the RL-8 form.
SVBREL8_ERRONEOUS_IND VARCHAR2 4 ERRONEOUS INDICATOR: This field indicates whether or not the student RL-8 is cancelled permanently. Values can be: Y - Yes, because this information should have never been filed. NULL - No, because the student personal information is changed, and an Orig
inal will be sent out after MRQ verifies the Cancellation.
SVBREL8_BOXB1_AMOUNT NUMBER 22 BOX B1 AMOUNT: This field stores tuition fees paid to a university, college or any other institution offering postsecondary education in relation to an institutional program at the post-secondary school level for a session, provided they are attributable
to a study session the student started before March 28, 2013. These fees can be claimed at a rate of 20%. This is applied only for tax year 2013.
SVBREL8_BOXB2_AMOUNT NUMBER 22 BOX B2 AMOUNT: This field stores tuition fees paid to a university, college or any other institution offering postsecondary education in relation to an institutional program at the post-secondary school level for a session, provided they are attributable
to a study session the student started after March 27, 2013. These fees can be claimed at a rate of 8%. This is applied only for tax year 2013.
SVBREL8_USER_ID VARCHAR2 120 USER ID: The user ID of the person who inserted or last updated this record.
SVBREL8_VPDI_CODE VARCHAR2 24 VPDI CODE: Multi-entity processing code.
