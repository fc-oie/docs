SFRGEFM

Below are the column names for SFRGEFM.

Columns for SFRGEFM
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
SFRGEFM_INST_NAME VARCHAR2 260 INSTITUTION NAME: Official name of the institution.
SFRGEFM_BATCH_ID NUMBER 22 BATCH ID: Unique ID generated for a batch of records that are inserted into this table when Gainful Employment Submittal process is run with the file export type T
SFRGEFM_AIDY_CDE VARCHAR2 16 AID YEAR CODE: This field indicates the aid year.
SFRGEFM_AWARD_YEAR VARCHAR2 32 AWARD YEAR: Award Year the student was enrolled in the program.
SFRGEFM_PIDM NUMBER 22 PIDM: Internal identification number of the person.
SFRGEFM_ID VARCHAR2 36 ID: This field defines the identification number used to access person on-line.
SFRGEFM_ACTIVITY_DATE DATE 7 ACTIVITY DATE: The date that information in this record was entered or last updated.
SFRGEFM_USER_ID VARCHAR2 120 USER ID: The user ID of the person who inserted or last updated this record.
SFRGEFM_FILE_TYPE VARCHAR2 4 FILE TYPE: Value to indicate the specific type of GE file. S for submittal and R for resubmittal.
SFRGEFM_MED_DENT_IND VARCHAR2 4 MEDICAL OR DENTAL INDICATOR: Medical or Dental Internship or Residency Program.
SFRGEFM_LAST_NAME VARCHAR2 240 LAST NAME: This field defines the last name of person.
SFRGEFM_FIRST_NAME VARCHAR2 240 FIRST NAME: This field identifies the first name of person.
SFRGEFM_SSN VARCHAR2 60 SOCIAL SECURITY NUMBER: This field displays person social security number.
SFRGEFM_BIRTH_DATE DATE 7 BIRTH DATE: This field displays person birth date.
SFRGEFM_SYSTEM_MANUAL_IND VARCHAR2 4 SYSTEM OR MANUAL INDICATOR: Indicator to denote whether the record is created by the system or created or updated manually by the user. S denotes System and M denotes Manual.
SFRGEFM_PROG_ATND_STATUS VARCHAR2 4 PROGRAM ATTENDENCE STATUS: The attendance status of the student in the educational program. G - Graduated; W - Withdrew; E - Enrolled.
SFRGEFM_SURROGATE_ID NUMBER 22 SURROGATE ID: The surrogate id for this record.
SFRGEFM_PROGRAM_NAME VARCHAR2 320 INSTITUTIONAL PROGRAM NAME: Institutional name of the program the student was enrolled in during the award year.
SFRGEFM_PROG_BEGN_DATE DATE 7 PROGRAM BEGIN DATE: Date student began enrollment in the educational program.
SFRGEFM_AY_PROG_BEGN_DATE DATE 7 PROGRAM BEGIN DATE AWARD YEAR: Date in this award year student began enrollment in the educational program.
SFRGEFM_FIRST_ENRL_STATUS VARCHAR2 4 ENROLLMENT STATUS: Code for the student’s enrollment status as of the 1st day in the GE program. Values are: F - Full-Time; Q - Three-Quarter Time; H - Half-Time; L - Less Than Half-Time.
SFRGEFM_PROG_STATUS_DATE DATE 7 PROGRAM STATUS DATE: The date of student’s graduation or withdrawal from the GE Program.
SFRGEFM_MI VARCHAR2 240 MIDDLE NAME: This field identifies the middle name of person.
SFRGEFM_OPEID VARCHAR2 32 OPEID: The institution’s 8-digit ED Office of Postsecondary Education (OPE) code used to identify the institution.
SFRGEFM_CIPC_CODE VARCHAR2 24 CIPC CODE: This field identifies the Classification of Institutional Programs (CIP) code associated with the major area of study.
SFRGEFM_CREDENTIAL_LEVEL VARCHAR2 8 CREDENTIAL LEVEL: Credential Level of the program the student was enrolled in during this award year.
SFRGEFM_PRIVATE_LOAN_AMT NUMBER 22 PRIVATE LOAN AMOUNT: Gross amount of private educational loans received by the student at any time for attendance in the GE Program.
SFRGEFM_INST_DEBT_AMT NUMBER 22 INSTITUTIONAL DEBT AMOUNT : Total amount of institutional debt owed by the student for attendance in any GE Program at the institution as of the day the student graduated or withdrew from the program, not just for this award year.
SFRGEFM_TUTION_FEE_AMT NUMBER 22 TUTION FEE AMOUNT: Total amount of tuition and fees charged the student for the entire program (not just for this award year).
SFRGEFM_BOOK_SUPP_AMT NUMBER 22 BOOKS, SUPPLIES AND EQUIPMENT AMOUNT: Allowance amount in Cost of Attendance (COA) for books, supplies, and equipment charged the student for the entire program (not just for this award year).
SFRGEFM_PROGRAM_LENGTH NUMBER 22 PROGRAM LENGTH: The length of the instructional program in weeks, months, or years.
SFRGEFM_PROG_LENGTH_TYPE VARCHAR2 4 PROGRAM LENGTH TYPE: The unit of measure for the length of the instructional program. Values are: W - Weeks, M - Months and Y - Years.
SFRGEFM_SUBMITTAL_DATE DATE 7 SUBMISSION DATE: The date the GE Submittal File was created.
SFRGEFM_CREATED_DATE DATE 7 CREATED DATE: The date on which the record was created when the Gainful Employment Submittal process is run with the file export type T.
SFRGEFM_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: The latest source for the data contained in this record.
SFRGEFM_VERSION NUMBER 22 VERSION: The optimistic lock token for this record.
SFRGEFM_VPDI_CODE VARCHAR2 24 VPDI CODE: The code representing the entity to which this record belongs to for Multi-entity Processing support.
SFRGEFM_PRIVATE_LOAN_AIDY_AMT NUMBER 22 PRIVATE LOAN AIDY AMOUNT: Gross amount of private educational loans received by the student during the aid(award) year for attendance in the GE Program.
SFRGEFM_TUTION_FEE_AIDY_AMT NUMBER 22 TUTION FEE AIDY AMOUNT: Total amount of tuition and fees charged the student for this aid(award) year.
SFRGEFM_BOOK_SUPP_AIDY_AMT NUMBER 22 BOOKS SUPPLIES AND EQUIPMENT AIDY AMOUNT: Allowance amount in Cost of Attendance(COA) for books,supplies,and equipment charged the student for this aid(award) year.
SFRGEFM_TOTAL_COA_AIDY_AMT NUMBER 22 TOTAL COA AIDY AMOUNT: Total Cost of Attendance (COA) for the aid(award) year.
SFRGEFM_HOUSING_FOOD_AIDY_AMT NUMBER 22 HOUSING FOOD AIDY AMOUNT: Allowance amount in Cost of Attendance(COA) for housing and food for the aid(award) year.
SFRGEFM_INST_GRANT_AIDY_AMT NUMBER 22 INSTITUTION GRANTS AIDY AMOUNT: Institution grants and scholarships for the aid(award) year.
SFRGEFM_INST_GRANT_AMT NUMBER 22 INSTITUTION GRANTS AMOUNT: Institution grants and scholarships for the entire program(not just for this award year).
SFRGEFM_STATE_PRIVATE_AIDY_AMT NUMBER 22 OTHER STATE PRIVATE AIDY AMOUNT: Other state, tribal, or private grants for the aid(award) year
SFRGEFM_CTP_PROGRAM_IND VARCHAR2 4 CTP PROGRAM INDICATOR: Comprehensive Transition and Postsecondary(CTP) program indicator.
SFRGEFM_APP_PRISON_IND VARCHAR2 4 PRISON EDUCATION: Indicates if the program is considered an approved prison education program.
SFRGEFM_RES_TUIT_STATUS VARCHAR2 8 RESIDENCY TUITION STATUS: The student’s residency tuition status by State or district for the Award Year being reported.Values are IS (In-State Tuition), ID (In-District Tuition) and OS (Out-of-State Tuition).
SFRGEFM_INVALIDATE_IND VARCHAR2 4 INVALIDATE INDICATOR: Indicates if the student’s record should invalidate any previous record sent to the agency.Valid values are (Y)es or (N)o.
SFRGEFM_WEEKS_IN_YEAR NUMBER 22 WEEKS IN YEAR: This value is the number of weeks in the standard academic year.
SFRGEFM_GE_PROGRAM_IND VARCHAR2 4 GAINFUL EMPLOYMENT PROGRAM: Indicates if the program is considered a Gainful Employment by government definition. Valid values are (Y)es or (N)o.
SFRGEFM_QUALIFYING_GRD_PGM_CDE VARCHAR2 4 QUALIFYING GRADUATE PROGRAM INDICATOR: Program is a “qualifying graduate program”. (Yes, No, Not Applicable)
