Below are the column names for GURFEED.

Columns for GURFEED
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
GURFEED_SYSTEM_ID VARCHAR2 32 SYSTEM IDENTIFICATION: Contains the system identifier from which the transaction originated. Values: ACTRECV - Accounts Receivable, PAYROLL - Human Resources, ALUMNI - Alumni, etc.
GURFEED_SYSTEM_TIME_STAMP VARCHAR2 56 SYSTEM TIME STAMP: The time of the day attached by the system to every record when entered into the system.
GURFEED_DOC_CODE VARCHAR2 32 DOCUMENT CODE: The unique number of the document being updated.
GURFEED_REC_TYPE VARCHAR2 4 RECORD TYPE INDICATOR: The indicator of the type of record (type 1 or type 2).
GURFEED_SUBMISSION_NUMBER NUMBER 22 SUBMISSION NUMBER: The number of allowable submissions for a reusable/recurring document.
GURFEED_ITEM_NUM NUMBER 22 COMMODITY ITEM NUMBER: The literal commodity or goods description associated with an invoice processing record.
GURFEED_SEQ_NUM NUMBER 22 SEQUENCE NUMBER: A system generated sequence number relating to transactions within a document.
GURFEED_ACTIVITY_DATE DATE 7 ACTIVITY DATE: Date the record was created or last updated.
GURFEED_USER_ID VARCHAR2 120 USER ID: The unique identification code of the user.
GURFEED_RUCL_CODE VARCHAR2 16 RULE CLASS CODE: The four character alphanumeric code identifying an accounting transaction rule class.
GURFEED_DOC_REF_NUM VARCHAR2 140 DOCUMENT REFERENCE NUMBER: The user-defined number providing additional identification for the encumbrance.
GURFEED_TRANS_DATE DATE 7 TRANSACTION DATE: The date the transaction was processed.
GURFEED_TRANS_AMT NUMBER 22 TRANSACTION AMOUNT: The dollar amount of the transaction associated with this particular account distribution.
GURFEED_TRANS_DESC VARCHAR2 140 TRANSACTION DESCRIPTION: A brief description of the purpose of the journal voucher record being created.
GURFEED_DR_CR_IND VARCHAR2 4 DEBIT/CREDIT INDICATOR: This debit or credit indicator is used for all general ledger transactions. The plus (+) or minus (-) indicators are used for all operating account ledger (OPAL) transactions.
GURFEED_BANK_CODE VARCHAR2 8 BANK CODE: A user-defined value that is used for identification purposes on all cash transactions.
GURFEED_OBUD_CODE VARCHAR2 24 OPERATING BUDGET CODE: The user-defined unique identifier of a budget id.
GURFEED_OBPH_CODE VARCHAR2 24 OPERATING BUDGET PHASE CODE: The user-defined identifier for a budget phase. The budget phase in combination with budget identifier (obud_code) uniquely identifies a budget in the budget system.
GURFEED_BUDG_DUR_CODE VARCHAR2 4 BUDGET DURATION CODE: Duration code is as follows: P = Permanent Budget Amounts, T = Temporary Budget Amounts.
GURFEED_COAS_CODE VARCHAR2 4 CHART OF ACCOUNTS CODE: The primary identification code for any chart of accounts that uniquely identifies that chart from any other in a multi-chart environment.
GURFEED_ACCI_CODE VARCHAR2 24 ACCOUNT INDEX CODE: The user-defined value representing a summarization of any combination of user-defined FOAPAL elements.
GURFEED_FUND_CODE VARCHAR2 24 FUND CODE: Identifies the fund code that appears on a transaction.
GURFEED_ORGN_CODE VARCHAR2 24 ORGANIZATION CODE: Identifies the organization code that appears on a transaction.
GURFEED_ACCT_CODE VARCHAR2 24 ACCOUNT CODE: The user-defined value representing an account.
GURFEED_PROG_CODE VARCHAR2 24 PROGRAM CODE: The user-defined value to the program classification structure as defined by the National Council of Higher Education Management Systems.
GURFEED_ACTV_CODE VARCHAR2 24 ACTIVITY CODE: The activity that is primarily associated with this organization.
GURFEED_LOCN_CODE VARCHAR2 24 LOCATION CODE: The physical location of the institution financial manager. For example, Vice President, Finance, Suite 10 Adams Hall, Main Campus.
GURFEED_DEP_NUM VARCHAR2 32 DEPOSIT NUMBER: The deposit number assigned to this transaction.
GURFEED_ENCD_NUM VARCHAR2 32 ENCUMBRANCE NUMBER: The unique number of a document.
GURFEED_ENCD_ITEM_NUM NUMBER 22 ENCUMBRANCE COMMODITY ITEM NUMBER: The literal commodity or goods description associated with an invoice processing record.
GURFEED_ENCD_SEQ_NUM NUMBER 22 ENCUMBRANCE SEQUENCE NUMBER: The sequence number for the account distribution within the referenced encumbrance number being effected.
GURFEED_ENCD_ACTION_IND VARCHAR2 4 ENCUMBRANCE ACTION INDICATOR: Indicators are as follows: T = Total, P = Partial, A = Adjustment.
GURFEED_PRJD_CODE VARCHAR2 32 PROJECT CODE: If the encumbrance is related to project (work order) from cost accounting, enter the project code.
GURFEED_DIST_PCT NUMBER 22 DISTRIBUTION PERCENTAGE: The percentage of the total encumbrance to be assigned to this accounting distribution. If a percentage is entered, the system calculates the amount, otherwise, an amount must be entered.
GURFEED_BUD_DISPN VARCHAR2 4 BUDGET DISPOSITION: The indicator that determines the year-end processing or budget requested encumbrance amounts.
GURFEED_CMT_TYPE VARCHAR2 4 ENCUMBRANCE COMMITTMENT TYPE: The encumbrance roll indicator.
GURFEED_CMT_PCT NUMBER 22 ENCUMBRANCE COMMITTED PERCENTAGE: If the encumbrance is committed, this is the percentage of value to commit.
GURFEED_ENCB_TYPE VARCHAR2 4 ENCUMBRANCE TYPE: The types are as follows: R = Register, P = Purchase Order, E = Encumbrance, L = Labor, M = Memo.
GURFEED_VENDOR_PIDM NUMBER 22 VENDOR PERSONAL IDENTIFICATION MASTER: The unique personal identification master of a vendor.
GURFEED_ONE_TIME_VEND_CODE VARCHAR2 36 ONE TIME VENDOR CODE: This column reserved for future use.
GURFEED_BUDGET_PERIOD VARCHAR2 8 BUDGET PERIOD: The numeric value of the budget period being entered if this is a budget journal.
GURFEED_ACCRUAL_IND VARCHAR2 4 ACCRUAL INDICATOR: This indicator is used during the accrual period. If set to Y, the system automatically generates transactions for both current and prior fiscal years.
GURFEED_ABAL_OVERRIDE VARCHAR2 4 AVAILABLE BUDGET OVERRIDE: This indicator is used to override the availability of funds checking process, if the user has the authority.
GURFEED_ID VARCHAR2 36 IDENTIFICATION: The identification number of the person with a student A/R detail transaction which is being fed.
GURFEED_TRAN_NUMBER VARCHAR2 32 TRANSACTION NUMBER: The transaction number of the item on the persons A/R account.
GURFEED_DETAIL_CODE VARCHAR2 16 DETAIL CODE: The detail code of the transaction on the persons A/R account.
GURFEED_TERM_CODE VARCHAR2 24 TERM CODE: The term code of the of the transaction on the persons A/R account.
GURFEED_ACCOUNT VARCHAR2 240 ACCOUNT NUMBER: The account number associated with the detail code of the persons A/R detail transaction.
GURFEED_SRCE_CODE VARCHAR2 4 SOURCE CODE: The source code indicating the origin of the persons A/R detail transaction. (e.g. (R)egistration, (D)eposit, (M)emo, etc.)
GURFEED_EFFECTIVE_DATE VARCHAR2 44 EFFECTIVE DATE: The effective date of the A/R transaction being fed. In most cases, this would be <= the date that the feed is being run. On option, detail transactions with future effective dates can be fed.
GURFEED_PAYT_CODE VARCHAR2 4 PAYMENT TYPE INDICATOR: The type of payment represented by the detail code for this A/R transaction (cash, financial aid, etc.).
GURFEED_DETAIL_CODE2 VARCHAR2 16 DETAIL CODE2: The detail code for the other side of an application of payments (APPL) tran. For the charge side, this field will contain the pay detail code applied to the charge. This field will be null for non-APPL transactions.
GURFEED_PAYT_CODE2 VARCHAR2 4 PAYMENT TYPE INDICATOR: The type of payment represented by the detail code 2. This field will be null for non-APPL transactions.
GURFEED_CURR_CODE VARCHAR2 16 CURRENCY CODE: A code which uniquely identifies a type of currency.
GURFEED_FOREIGN_AMOUNT NUMBER 22 FOREIGN AMOUNT: Amount stated in foreign currency. Dollar amount conversion based on currency code and base dollars.
GURFEED_PTOT_STATUS VARCHAR2 4 POSITION TOTAL STATUS: Either A (Active) or W (Working).
GURFEED_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key
GURFEED_VERSION NUMBER 22 VERSION: Optimistic lock token.
GURFEED_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: Source system that created or updated the data.
GURFEED_VPDI_CODE VARCHAR2 24 VPDI CODE: Multi-entity processing code.
