RPBLOPT

Below are the column names for RPBLOPT.

Columns for RPBLOPT
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
RPBLOPT_AIDY_CODE VARCHAR2 16 AID YEAR CODE: The aid year associated with the information contained in this record.
RPBLOPT_CREATE_APP_IND VARCHAR2 4 CREATE APPLICATION INDICATOR: This indicator determines whether a loan accepted within the Packaging Module will automatically create a loan application. Valid values are (Y)es and (N)o which defaults to (N)o.
RPBLOPT_SAT_TREQ_IND VARCHAR2 4 SATISFY LOAN APPLICATION REQUIREMENT INDICATOR: This field indicates whether a loan application requirement will should be satisfied by the entry of aa loan application. Valid values are (Y)es or (N)o with a default of (N)o.
RPBLOPT_MEMO_LOAN_AMT_IND VARCHAR2 4 REQUIRE APPLICATION OR ORIGINATION FOR MEMO: For DL, indicates an origination must exist in order for a loan to memo. If this indicator is N and an origination does not exist, an estimated memo amount will be calculated based on the award amount and the
DL fee table. For EL and Manual, indicates an application must exist in order to memo. If this indicator is N, the full award amount will memo without any fees subtracted.
RPBLOPT_CREATE_AWARD_IND VARCHAR2 4 CREATE AWARD INDICATOR: This indicator determines whether a loan application entered in the loan module should automatically create an award if one does not exist within the applicant’s package. Valid values (Y)es and (N)o.
RPBLOPT_USE_RQST_AMT_IND VARCHAR2 4 USE REQUESTED AMOUNT INDICATOR: This field determines whether the award amount when posted should be posted as the loan requested amount, or as a zero. (Y)es indicates to post the student’s award with the requested loan amount.
RPBLOPT_FUND_CODE VARCHAR2 24 FUND CODE: This field identifies the fund code that will be added to the students award record if the Create Award Indicator is set to (Y)es.
RPBLOPT_ACTIVITY_DATE DATE 7 ACTIVITY DATE: The date that information in this record was entered or last updated.
RPBLOPT_LNST_CODE VARCHAR2 16 INITIAL LOAN STATUS: This field is used to identify the loan status to be used when the system creates a loan application. This can only be maintained when the loan accepted indicator is set to (Y)es.
RPBLOPT_LENDER_ID VARCHAR2 24 DEFAULT LENDER ID: This code identifies the default lender ID to be used during loan processing.
RPBLOPT_TREQ_CODE VARCHAR2 24 LOAN APPLICATION TRACKING REQUIREMENT CODE: This field identifies the tracking requirement code to be used when the system satisfies a loan application requirement. This can only be maintained when Satis.Loan Req. Indicator= (Y).
RPBLOPT_TRST_CODE VARCHAR2 4 TRACKING REQUIREMENT STATUS CODE: This code identifies the requirement status code to be used when the system satisfies a loan application requirement. This can only be maintained when the Satisfy Loan Application Indicator is (Y)es.
RPBLOPT_AWST_CODE VARCHAR2 16 AWARD STATUS CODE: This field identifies the award status code which a loan award will be added to the students award record if the Create Award indicator is set to (Y)es.
RPBLOPT_CREATE_APP_TREQ_IND VARCHAR2 4 LOAN APPLICATION APPLICATION TRACKING INDICATOR: Indicator to be used for creation of a loan application when the loan application tracking requirement is satisfied.
RPBLOPT_DL_PN_REQ_ORIG_IND VARCHAR2 4 NA
RPBLOPT_DL_DISB_REQ_ORIG_IND VARCHAR2 4 DL PROMISSORY NOTE REQUIRED INDICATOR: Indicates if a promissory note is required before sending an origination record.
RPBLOPT_DL_ORIG_REQ_DISB_IND VARCHAR2 4 DL ORIGINATION ACKNOWLEDGEMENT INDICATOR: Indicates if servicer must acknowledge receipt of an origination record prior to disbursement.
RPBLOPT_DL_PN_REQ_DISB_IND VARCHAR2 4 DIRECT LOAN MPN LINKED INDICATOR: Indicates if the MPN must be linked by COD to the origination prior to disbursement.
RPBLOPT_RETURN_PIDM NUMBER 22 RETURN PIDM: The internal pidm for the default Agency/Lender to whom unused funds are to be returned for this loan code.
RPBLOPT_LENDER_PIDM NUMBER 22 LENDER PIDM: The internal pidm for the default Lender associated with this loan code.
RPBLOPT_GUAR_PIDM NUMBER 22 GUARANTOR PIDM: The internal pidm for the default Guarantee Agency associated with this loan code.
RPBLOPT_CERT_REQUEST_AMT_IND VARCHAR2 4 CERTIFICATION REQUEST AMOUNT INDICATOR: If the loan requested amount is required for certification, this will be Y.
RPBLOPT_DETAIL_CODE_RET_STU VARCHAR2 16 RETURNED CHECK STUDENT DETAIL CODE: The charge/payment detail code to be used on the student account when a returned check amount is processed by the disbursement process.
RPBLOPT_DETAIL_CODE_LNDR_PMT VARCHAR2 16 RETURNED CHECK LENDER PAYMENT DETAIL CODE: The payment detail code to be used on the lender account when a returned check amount is processed on a student account by the disbursement process.
RPBLOPT_DETAIL_CODE_LNDR_REF VARCHAR2 16 RETURNED CHECK LENDER REFUND DETAIL CODE: The charge detail code to be used on the lender account to allow a refund to the lender when a returned check amount is processed on a student account by
the disbursement process.
RPBLOPT_AUTHORIZE_IND VARCHAR2 4 LOAN AUTHORIZATION INDICATOR: Indicates whether to create loan authorizations for this aid year and fund code when disbursing funds.
RPBLOPT_DISB_AMT_IND VARCHAR2 4 LOAN DISBURSEMENT AMOUNT INDICATOR: This field indicates whether to prevent loan disbursement if Disbursement Amount > Award Amount.
RPBLOPT_EL_AUDIT_IND VARCHAR2 4 CHANGE TRANSACTION INDICATOR: Flags whether or not the school will use CommonLine Change Transaction processing. Default value is Null. Valid values: Y yes, Null means No.
RPBLOPT_USER_ID VARCHAR2 30 USER ID: The user ID of the person who inserted or last updated this record.
RPBLOPT_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key
RPBLOPT_VERSION NUMBER 22 VERSION: Optimistic lock token.
RPBLOPT_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: Source system that created or updated the data.
RPBLOPT_VPDI_CODE VARCHAR2 24 VPDI CODE: Multi-entity processing code.
RPBLOPT_RESCHED_DISB_DATE_IND VARCHAR2 4 RESCHEDULE DISBURSEMENT DATE: Indicator to reschedule the disbursement dates for the Direct Loan fund based on the defined disbursement date offset rules.
RPBLOPT_MPN_MEMO_IND VARCHAR2 4 MPN REQUIRED FOR MEMO INDICATOR: Indicates if a valid MPN is required for the loan to memo. If the Direct Loan MPN Linked Indicator is checked, then the MPN must also be linked to this Loan by COD.
RPBLOPT_SINGLE_ORIG_IND VARCHAR2 4 SINGLE ORIGINATION INDICATOR: Indicates if increases to an award amount should update an existing origination or create a new origination.
RPBLOPT_AWARD_UPDATE_IND VARCHAR2 4 AWARD UPDATE INDICATOR: Indicates if updates made on the origination record are automatically updated on the award or if the user should be prompted for the update.
