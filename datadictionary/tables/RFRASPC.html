RFRASPC

Below are the column names for RFRASPC.

Columns for RFRASPC
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
RFRASPC_AIDY_CODE VARCHAR2 16 AID YEAR CODE: The aid year to be associated with information in this record. EXAMPLES: 9091, 9192, 9293, etc.
RFRASPC_FUND_CODE VARCHAR2 24 FUND CODE: This field identifies the fund associated with the information in this record.
RFRASPC_BUDG_ALLOC_AMT NUMBER 22 BUDGET ALLOCATED AMOUNT: This field represents the actual allocated budget for a fund code within the given aid year. Optional field which defaults to 0.
RFRASPC_AVAIL_OFFER_AMT NUMBER 22 AVAILABLE AMOUNT TO OFFER: This field represents the dollar amount of the fund that can be offered including any over-commitment amount. This field will be calculated if an Available to Offer Percent is entered.
RFRASPC_AVAIL_OFFER_PCT NUMBER 22 PERCENTAGE AMOUNT AVAILABLE TO OFFER: This optional field represents the percentage of the total allocation that the institution wishes to offer including over-commitment.
RFRASPC_AUTO_PACK_IND VARCHAR2 4 AUTOMATIC PACKAGE INDICATOR: This indicator is used to define whether this fund code should be included in automatic packaging.
RFRASPC_AUTO_SCHED_IND VARCHAR2 4 AUTOMATIC SCHEDULING INDICATOR: This indicator is used to define if this fund code, once awarded should be automatically scheduled between periods.
RFRASPC_AUTO_ACCEPT_IND VARCHAR2 4 AUTOMATIC ACCEPTANCE INDICATOR: This indicator is used to define if this fund should be automatically scheduled for disbursements.
RFRASPC_DISBURSE_IND VARCHAR2 4 DISBURSE INDICATOR: This indicator defines how the disbursements can be made for each fund. Disbursements can be (S)ystem, (M)anual, or (N)either.
RFRASPC_APPL_MEMO_IND VARCHAR2 4 APPLY FOR MEMO CREDIT: This field defines when and if the fund can be carried as a credit memo based on fund award status. Valid values include (N)one, (A)ccepted, (O)ffered.
RFRASPC_REPLACE_TFC_IND VARCHAR2 4 REPLACE TOTAL FAMILY CONTRIBUTION INDICATOR: This indicator is used to define whether or not this fund should replace the total family contribution in the calculation of unmet need.
RFRASPC_REDUCE_NEED_IND VARCHAR2 4 REDUCE NEED INDICATOR: This indicator is used to define whether or not this fund should reduce need in the calculation of unmet need. It is mutually exclusive from the Replace TFC indicator.
RFRASPC_OVERRIDE_IND VARCHAR2 4 OVERRIDE INDICATOR: This field indicates whether general tracking requirements (those not associated with a fund) can be overridden for the particular fund in order for disbursements to be made.(See Field Usage Notes for all cases.)
RFRASPC_ROUND_SCHED_IND VARCHAR2 8 ROUND SCHEDULE: This field defines the rounding rules used in scheduling the award by periods and for use in fund disbursement.
RFRASPC_EQUITY_IND VARCHAR2 4 EQUITY INDICATOR: This field is used to define whether the fund should be considered in Equity packaging.
RFRASPC_OFFER_AWST_CODE VARCHAR2 16 OFFER AWARD STATUS: This field defines the award status which this fund will be offered in an automated packaging environment.
RFRASPC_ACCEPT_AWST_CODE VARCHAR2 16 ACCEPT AWARD STATUS CODE: This code defines the award status with which this fund will be accepted.
RFRASPC_DECLINE_AWST_CODE VARCHAR2 16 DECLINE AWARD STATUS CODE: This field identifies the decline status that should be used to decline awards for this fund code.
RFRASPC_INEL_BEF_CUT_DATE_IND VARCHAR2 4 IF INELIGIBLE BEFORE CUT-OFF: This field determines what action will take place in the disbursement process if the student becomes ineligible for the fund prior to the financial aid cut-off date.
RFRASPC_INEL_AFT_CUT_DATE_IND VARCHAR2 4 IF INELIGIBLE AFTER CUT-OFF: This field determines what action will take place in the disbursement process if the student becomes ineligible for the funds after the institutions cut-off date.
RFRASPC_CHANGE_LOAD_IND VARCHAR2 4 CHANGE LOAD IND: Field indicates whether the award should be prorated or the scheduled disbursement prorated if the enrollment changes.
RFRASPC_RECOUP_IND VARCHAR2 4 RECOUP INDICATOR: This field indicates whether dollars should be recouped after disbursements for this fund if something changes in the students record.
RFRASPC_LOAN_PROCESS_IND VARCHAR2 4 LOAN PROCESS INDICATOR: This field is used to determine whether this fund is to be included in the loan processing function.
RFRASPC_NA_REQD_IND VARCHAR2 4 NEED ANALYSIS INDICATOR: This indicator defines whether this fund requires that a need analysis record be on file for this fund to be awarded or for loan processing to occur.
RFRASPC_SEL_VER_INC_IND VARCHAR2 4 SELECTED FOR VERIFICATION INDICATOR: This field indicates whether disbursements can be made on the fund if the verification has not been completed.
RFRASPC_ACTIVITY_DATE DATE 7 ACTIVITY DATE: The date that information in this record was entered or last updated.
RFRASPC_TRANSFER_AMT NUMBER 22 TRANSFER AMOUNT: This field represents any dollar amount which should transfer in or transfer out of a fund which will affect the total allocation for the Aid Year. Optional with a default value of 0. This field can be negative.
RFRASPC_PRIOR_BAL_AMT NUMBER 22 PRIOR BALANCE AMOUNT: This field represents any prior balance for the fund code from a previous aid year. Optional field with a default value of 0.
RFRASPC_TOTAL_ALLOC_AMT NUMBER 22 TOTAL ALLOCATED: This calculated field displays the total available dollars for the fund for the aid year. It is the sum of the prior balance the transferred amount plus the budget allocated amount. Not user-enterable.
RFRASPC_ORIG_OFFER_NO NUMBER 22 ORIGINAL OFFER NUMBER: This field maintains the number of original awards for the fund in the specified aid year.
RFRASPC_ORIG_OFFER_AMT NUMBER 22 ORIGINAL OFFER AMOUNT: This field maintains the dollar amount of all original awards for the fund in the specified aid year.
RFRASPC_OFFER_NO NUMBER 22 OFFER NUMBER: This field maintains the number of awards that are currently offered for the fund in the specified aid year.
RFRASPC_OFFER_AMT NUMBER 22 OFFER AMOUNT: This field maintains the dollar amount of awards that have been offered for the fund in the specified aid year.
RFRASPC_ACCEPT_NO NUMBER 22 NUMBER OF ACCEPTED: This field maintains the number of awards that have been accepted for this fund in the specified aid year.
RFRASPC_ACCEPT_AMT NUMBER 22 ACCEPTED AMOUNT: This field maintains the dollar amount of the fund that has been accepted for the indicated aid year.
RFRASPC_DECLINE_NO NUMBER 22 DECLINE NUMBER: This field maintains the number of awards that have been declined for this fund code in the specified aid year.
RFRASPC_DECLINE_AMT NUMBER 22 DECLINE AMOUNTS: This field maintains the dollar amount of declined awards for the fund code in the specified year.
RFRASPC_CANCEL_NO NUMBER 22 CANCELLED AWARDS: This field maintains the number of cancelled awards for the fund code in the specified aid year.
RFRASPC_CANCEL_AMT NUMBER 22 CANCELLED AMOUNT: This field maintains the dollar amount of cancelled awards for the fund code in the specified aid year.
RFRASPC_AUTHORIZE_NO NUMBER 22 AUTHORIZED AWARDS: This field maintains the number of awards that have been authorized for the fund in the specified aid year.
RFRASPC_AUTHORIZE_AMT NUMBER 22 AUTHORIZED AMOUNT: This field maintains the dollar amount of awards that are authorized.
RFRASPC_MEMO_NO NUMBER 22 MEMO AWARDS: This field maintains the number of memo’d awards for the fund code in the specified aid year.
RFRASPC_MEMO_AMT NUMBER 22 MEMO AMOUNT: This field maintains the dollar amount of memo’d awards for the f und code in the specified aid year.
RFRASPC_PAID_NO NUMBER 22 PAID NUMBER: This field maintains the number of awards that have been paid for the fund in the specified aid year.
RFRASPC_PAID_AMT NUMBER 22 PAID AMOUNT: This field maintains the dollar amount of awards that have been paid for the fund in the specified aid year.
RFRASPC_MAX_AWARD_AMT NUMBER 22 MAXIMUM DOLLAR AMOUNT AWARDED TO A STUDENT: This field represents the maximum award the institution wishes to offer to any one student from a specific fund. Cannot be negative and cannot be less than the award minimum.
RFRASPC_MIN_AWARD_AMT NUMBER 22 MINIMUM DOLLAR AMOUNT AWARDED TO A STUDENT: This field represents the minimum award the institution wishes to offer to any one student from each specific fund.
RFRASPC_3QUARTER_LOAD_PCT NUMBER 22 THREE QUARTER LOAD PCT: Represents the percentage of the students award which will be disbursed if the student is enrolled on a three-quarter time basis.
RFRASPC_HALF_LOAD_PCT NUMBER 22 HALF LOAD PCT: This field represents the percentage of the students award that will be disbursed if the student is enrolled on a half-time basis.
RFRASPC_LESS_HALF_LOAD_PCT NUMBER 22 LESS THAN HALF LOAD PCT: This field represents the percentage of the students award that will be disbursed if the student is enrolled on a less than half- time basis.
RFRASPC_SELF_HELP_RED_PCT NUMBER 22 SELF-HELP REDUCTION PERCENTAGE: This field defines the percentage of this fund that can be used toward satisfying self-help requirements.
RFRASPC_LOAN_FEE_PCT NUMBER 22 LOAN FEE PERCENTAGE: This field represents the loan fee percent for this fund if a “Y” was indicated in the Loan Process field. Starting with the 1516 aid year this field is only used for Electronic and Manual Loan processing.
RFRASPC_PRORATION_IND VARCHAR2 4 PRORATION INDICATOR: Used by the Disbursement process to decide how to process disbursement when a students disbursement load > packaging load. Values are P = Prorate disbursement amount, D = Do not prorate, N = No disbursement.
RFRASPC_AWD_CHG_LTR_IND VARCHAR2 4 AWARD LETTER CHANGE INDICATOR: Indicates whether a change to this funds offered amount should set the RORSTAT_AWD_LTR_IND to ‘Y’. Valid values are Y (set the RORSTAT_AWD_LTR_IND = Y, N or blank = no change to RORSTAT indicator.
RFRASPC_PROM_REQ_IND VARCHAR2 4 PROMISSORY NOTE REQUIRED INDICATOR: Indicates whether this fund requires that the student sign a promissory note.
RFRASPC_OVERRIDE_NEED_IND VARCHAR2 4 OVERRIDE UNMET NEED: Override the validation of unmet need if this indicator is set.
RFRASPC_OVERRIDE_TREQ_IND VARCHAR2 4 OVERRIDE TRACKING REQUIREMENTS: Override the test for outstanding tracking requirements needed for packaging if indicator is set.
RFRASPC_OVERRIDE_SAPR_IND VARCHAR2 4 Indicator used to override the verification of satisfactory academic progress in the Packaging and Disbursement processes.
RFRASPC_NCAA_IND VARCHAR2 4 Indicator to allow users to track which funds are “countable” for NCAA purposes.
RFRASPC_LMS_FUND VARCHAR2 24 LMS (IA Plus) fund designation that indicates the fund-loan rules associated with an institutional based loan. This designation is carried on LMS feed transactions.
RFRASPC_INTEREST_RATE NUMBER 22 The interest rate on the direct loan for this student.
RFRASPC_DIRECT_LOAN_IND VARCHAR2 4 Indicates whether the loan is of a direct loan type.
RFRASPC_USE_DISB_ENRL_MEMO_IND VARCHAR2 4 USE DISBURSEMENT EDITS FOR MEMO: Allows the application of the Disbursement Enrollment Edits to be applied to funds in memo status.
RFRASPC_ALT_LOAN_PROG_TYPE_CDE VARCHAR2 12 ATERNATIVE LOAN PROGRAM TYPE CODE: 3-character code to indicate if the fund is an alternative loan fund as defined by NCHELP.
RFRASPC_REBATE_PERCENT NUMBER 22 INTEREST RATE FOR GRADUATE DIRECT LOANS: The interest rate on the direct loan for graduate students. Prior to the 2021-2022 aid year this field was used as rebate fee percent. Rebate fee percent is on RLRDFEE beginning from 2015-2016 aid year.
RFRASPC_WEB_ACCEPT_FLAG VARCHAR2 4 WEB ACCEPT FLAG: This controls which funds can be accepted/declined via the web. The valid values are ‘Y’ (Checked) and ‘N’ (unchecked).
RFRASPC_OVERRIDE_NEED_TO_COA VARCHAR2 4 OVERRIDE NEED TO COA: Fund level override indicator to allow need to be overridden up to the cost of attendance (budget) amount.
RFRASPC_ATTENDING_HR_IND VARCHAR2 4 ATTENDING HOURS INDICATOR: Indicator when checked to calculate the enrollment load for disbursement based on hours which the student is attending and the course has begun. Valid values are Y and null. Default value is null.
RFRASPC_EL_IND VARCHAR2 4 ELECTRONIC LOAN INDICATOR: The type of electronic loan assigned to the fund.
RFRASPC_MANUAL_LOAN_IND VARCHAR2 4 MANUAL LOAN INDICATOR: The type of manual loan assigned to the fund.
RFRASPC_ACG_YEAR VARCHAR2 4 ACG FUND YEAR LEVEL: Indicates the ACG Grant year funding level.
RFRASPC_SMART_YEAR VARCHAR2 4 SMART FUND YEAR LEVEL: Indicates the SMART Grant year funding level.
RFRASPC_AWRD_USING_EST_EFC_IND VARCHAR2 4 AWARD USING ESTIMATED EFC: Indicates if the fund can be awarded with an estimated EFC.
RFRASPC_ROLL_IND VARCHAR2 4 ROLL AWARD INDICATOR: Indicates if the fund is eligible for the award roll process.
RFRASPC_WEB_ACCEPT_AWST_CODE VARCHAR2 16 WEB ACCEPT AWARD STATUS CODE: The award status with which this fund will be accepted when awards are accepted by the student on the web.
RFRASPC_WEB_DECLINE_AWST_CODE VARCHAR2 16 WEB DECLINE AWARD STATUS CODE: The award status with which this fund will be declined when awards are declined by the student on the web.
RFRASPC_DISPLAY_PN_IND VARCHAR2 4 DISPLAY PN REQUIREMENT INDICATOR: Indicates whether Promissory Note requirements for this fund code should be displayed in Self-Service.
RFRASPC_WEB_LNDR_SELECT_IND VARCHAR2 4 WEB LENDER SELECTION INDICATOR: Indicates that the lender selection list should display for this fund code.
RFRASPC_TEACH_LEVEL VARCHAR2 4 TEACH FUND LEVEL: Indicates the TEACH Grant funding level.
RFRASPC_ROUND_AWARD_AMT NUMBER 22 ROUND AWARD: Specifies the nearest dollar amount to round down to during automatic packaging.
RFRASPC_USER_ID VARCHAR2 30 USER ID: The user ID of the person who inserted or last updated this record.
RFRASPC_PN_DESC VARCHAR2 60 PROMISSORY NOTE LONG DESCRIPTION: The long description of the promissory note.
RFRASPC_PN_URL VARCHAR2 255 PROMISSORY NOTE URL: The URL (Universal Resource Locator) associated with the promissory note.
RFRASPC_PN_INSTRUCTIONS VARCHAR2 2000 PROMISSORY NOTE INSTRUCTIONS: Instructions for the promissory note that will be displayed for the student in Self-Service.
RFRASPC_DISB_NO_DAYS NUMBER 22 DISBURSEMENT DATE OFFSET: Number of days prior to or after the disbursement date to calculate attending hours.
RFRASPC_REP_COURSE_IND VARCHAR2 4 REPEAT COURSE CHECKING INDICATOR: Not currently used.
RFRASPC_ENRR_CODE VARCHAR2 60 ENROLLMENT RULE CODE: The enrollment rule code used to disburse the fund.
RFRASPC_TEACH_REDUCTION_PCT NUMBER 22 TEACH REDUCTION PERCENTAGE: The percentage of the full award amount that TEACH will be reduced.
RFRASPC_CANCEL_AWST_CODE VARCHAR2 16 CANCEL AWARD STATUS CODE: The code which defines the award status with which this fund will be cancelled.
RFRASPC_MIX_OFFER_AWST_CODE VARCHAR2 16 MIXED OFFER AWARD STATUS CODE: The status code assigned when period statuses are not the same value and the award is determined to be offered.
RFRASPC_MIX_ACCEPT_AWST_CODE VARCHAR2 16 MIXED ACCEPT AWARD STATUS CODE: The status code assigned when period statuses are not the same value and the award is determined to be accepted.
RFRASPC_MIX_DECLINE_AWST_CODE VARCHAR2 16 MIXED DECLINE AWARD STATUS CODE: The status code assigned when period statuses are not the same value and the award is determined to be declined.
RFRASPC_ENABLE_PERIOD_AWARDING VARCHAR2 4 ENABLE PERIOD AWARDING: Indicates whether period awarding has been enabled.
RFRASPC_ACPT_PARTIAL_AMT_IND VARCHAR2 4 ACCEPT PARTIAL AMOUNT OPTION: Indicates whether the Accept Partial Amount option should be available to the student on the Accept Award Offer page in Self-Service.
RFRASPC_WEB_ACCEPT_OPTION VARCHAR2 4 WEB ACCEPT OPTION: Controls the level at which the fund can be accepted/declined in Self-Service.
RFRASPC_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key
RFRASPC_VERSION NUMBER 22 VERSION: Optimistic lock token.
RFRASPC_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: Source system that created or updated the data.
RFRASPC_VPDI_CODE VARCHAR2 24 VPDI CODE: Multi-entity processing code.
RFRASPC_ENABLE_BBAY VARCHAR2 4 ENABLE BBAY PROCESSING: Indicates whether Borrower-Based Academic Year processing has been enabled.
