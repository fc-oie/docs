COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS

RORCAMP_NBR_MTHS_PAY NUMBER 22 NUMBER OF MONTHS TO PAY: This field is a default for the number of months in which remaining payments will be made for Pell Payment Voucher purposes.

RORCAMP_DEC_PAY VARCHAR2 4 PELL DISBURSEMENTS IN DECEMBER: Indicates whether Pell disbursements are scheduled in December of this Aid Year for Pell payment purposes.
RORCAMP_JAN_PAY VARCHAR2 4 PELL DISBURSEMENTS IN JANUARY: Identifies whether Pell disbursements are scheduled in January of the Aid Year for Pell payment purposes.
RORCAMP_FEB_PAY VARCHAR2 4 PELL DISBURSEMENTS IN FEBRUARY: Identifies whether Pell disbursements are scheduled for February of the Aid Year for Pell payment purposes.
RORCAMP_MAR_PAY VARCHAR2 4 PELL DISBURSEMENTS IN MARCH: Indicates whether Pell disbursements are scheduled for March of the Aid Year for Pell payment purposes.

RORCAMP_JUN_PAY VARCHAR2 4 PELL DISBURSEMENTS IN JUNE: Indicates whether Pell disbursements are scheduled for June of the Aid Year for Pell payment purposes.

RORCAMP_PAYMENT_METHOD VARCHAR2 4 PAYMENT METHOD: This field indicates the default Payment Methodology used by the campus.
RORCAMP_EXPECT_WKS NUMBER 22 WEEKS ENROLLED: This field indicates the default number of weeks a student is enrolled in a year at this campus.
RORCAMP_WKS_IN_YR NUMBER 22 WEEKS IN PROGRAM: This field indicates the default number of weeks of instruction in the program year at this campus.

RORCAMP_MAIL_LINE2_INST_FAA VARCHAR2 75 INSTITUTIONAL MAILING ADDRESS LINE 2: Line 2 of the street or post office box address of the institution.
RORCAMP_MAIL_CITY_INST_FAA VARCHAR2 50 INSTITUTIONAL MAILING ADDRESS CITY: The city in which the institution is located.

RORCAMP_FAA_EMAIL VARCHAR2 128 FINANCIAL AID ADMINISTRATOR EMAIL ADDRESS: Internet address of an authorized Financial Aid Administrator of the institution.
RORCAMP_FAA_ADMIN_NAME VARCHAR2 500 FINANCIAL AID ADMINISTRATOR NAME: The full name (First Name, Middle Initial and Last Name without punctuation) of the institutional administrator officially responsible for the accuracy and completeness of the data. (e.g. JOHN E DOE)
RORCAMP_FAA_PHONE_AREA VARCHAR2 6 FINANCIAL AID ADMINISTRATOR PHONE AREA CODE: Area Code of the phone number for the official Financial Aid Administrator of the institution.
RORCAMP_FAA_PHONE_NO VARCHAR2 12 FINANCIAL AID ADMINISTRATOR PHONE NUMBER: Phone number for the official Financial Aid Administrator of the institution.
RORCAMP_FAA_PHONE_EXT VARCHAR2 10 FINANCIAL AID ADMINISTRATOR PHONE EXTENSION: Phone number extension for the official Financial Aid Administrator of the institution.
RORCAMP_FAA_FAX_AREA VARCHAR2 6 FINANCIAL AID ADMINISTRATOR FAX AREA CODE: Area Code of the fax number for the official Financial Aid Administrator of the institution.

RORCAMP_FAA_FAX_EXT VARCHAR2 10 FINANCIAL AID ADMINISTRATOR FAX EXTENSION: Fax number extension for the official Financial Aid Administrator of the institution.
RORCAMP_INST_TYPE VARCHAR2 4 INSTITUTION TYPE: Institution code that best describes this institution: 1=Less than 1 year; 2=1 year, less than 2 years; 3=2 years, less than 3 years; 4=3 years, less than 4 years; 5=4 years (baccalaureate); 6=5 years or more; others leave blank.
RORCAMP_INST_FIN_CONTROL VARCHAR2 4 INSTITUTION SOURCE OF FINANCIAL CONTROL: The source of financial control that best describes this institution: 1=Public; 2=Private, nonprofit; 3=Proprietary; others, leave blank.
RORCAMP_EL_SCHOOL_CDE VARCHAR2 24 EL SCHOOL CODE: This is the Dept of Ed school code to be used for Electronic Loan processing for this specific campus.
RORCAMP_TITLE_IV_RET_IND VARCHAR2 4 CAMPUS DEFAULT RETURN OF TITLE IV FUNDS RETURN INDICATOR: Indicates whether the institution has optionally decided to return funds on the student’s behalf to the Title IV programs for a particular campus. Valid values are Y, N, and Null.
RORCAMP_TITLE_IV_ROUND_IND VARCHAR2 4 CAMPUS DEFAULT RETURN OF TITLE IV FUNDS ROUNDING INDICATOR: Indicates if the final repayment amounts that the inst. and student are each responsible to return are rounded to the nearest dollar for a particular campus. Values are Y, N, and Null.
RORCAMP_EL_BRANCH_CDE VARCHAR2 8 EL BRANCH ID: The 2-digit campus ID associated with the 6-digit school code assigned by the Dept of Ed.
RORCAMP_PELL_FUND_CODE VARCHAR2 24 CAMPUS PELL FUND CODE: The Pell fund code to be used when awarding any applicant who belongs to this campus.
RORCAMP_TURN_OFF_PELL_IND VARCHAR2 4 INDICATOR TO TURN OFF PELL PROCESS: Indicator used to prevent Pell process from automatically running from forms for any students at this campus. Set to Y to prevent.
RORCAMP_COMMON_SCHOOL_ID VARCHAR2 32 CAMPUS COMMON SCHOOL ID: The entity ID unique to this campus.
RORCAMP_APPLY_FYFTB_RULE_IND VARCHAR2 4 APPLY FIRST-YEAR FIRST-TIME BORROWER RULE INDICATOR: Indicates that the first-year, first-time borrower rule should apply to Stafford loans.
RORCAMP_DL_SCHOOL_CODE VARCHAR2 24 DL SCHOOL CODE: The Department of Education’s school code to be used for Direct Loan processing for a specific campus.
RORCAMP_FED_SCHOOL_CODE VARCHAR2 24 CAMPUS FEDERAL SCHOOL CODE: The Federal School Code for the campus.
RORCAMP_OPEID VARCHAR2 24 CAMPUS OPEID: The OPEID for this particular campus.
RORCAMP_OPEID_BRANCH VARCHAR2 8 CAMPUS OPEID BRANCH: The OPEID Branch number for this particular campus.

RORCAMP_MAIL_LINE3_INST_FAA VARCHAR2 75 STREET LINE3: Line 3 of the street or post office box address of the institution.
RORCAMP_MAIL_LINE4_INST_FAA VARCHAR2 75 STREET LINE4: Line 4 of the street or post office box address of the institution.
RORCAMP_HOUSE_NUMBER VARCHAR2 10 HOUSE NUMBER: Institution’s building or lot number on a street or in an area.
RORCAMP_USER_ID VARCHAR2 30 USER ID: The user ID of the person who inserted or last updated this record.
RORCAMP_FAA_FAX_CTRY_CODE VARCHAR2 4 FINANCIAL AID ADMINISTRATOR FAX COUNTRY CODE: Country Code of the fax number for the official Financial Aid Administrator of the institution.
RORCAMP_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key
RORCAMP_VERSION NUMBER 22 VERSION: Optimistic lock token.
RORCAMP_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: Source system that created or updated the data.
RORCAMP_VPDI_CODE VARCHAR2 24 VPDI CODE: Multi-entity processing code.
RORCAMP_GUID VARCHAR2 144 GUID: Global Unique Identifier to uniquely identify the record of a resource for integration.
RORCAMP_CURRENT_TERM_CODE VARCHAR2 24 CURRENT TERM CODE: Current term of the campus.
RORCAMP_APRD_CODE VARCHAR2 24 DEFAULT AID PERIOD: Default aid period of the campus.
RORCAMP_APRD_ALGO_CODE VARCHAR2 120 DEFAULT AID PERIOD RULE CODE: Algorithmic rule code used to calculate the default aid period of the campus.
RORCAMP_SAPR_CODE VARCHAR2 24 INITIAL SAP CODE: The SAP status code assigned to a student when the first record of the student is created for the specific campus.
RORCAMP_TERM_CODE_SAP VARCHAR2 24 INITIAL SAP TERM CODE: The term code assigned to the student when the first SAP rules record of the student is created for the specific campus.
