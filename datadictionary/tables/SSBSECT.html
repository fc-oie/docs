Columns for SSBSECT
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
SSBSECT_TERM_CODE VARCHAR2 24 This field is not displayed on the form (page 0). It defines the Term code for the course section information. It is derived from the Key Block Term.
SSBSECT_CRN VARCHAR2 20 This field is not displayed on the form (page 0). It will display the Course Reference Number (CRN) assigned to this course section when it was initially added.
SSBSECT_PTRM_CODE VARCHAR2 12 This field is used to specify the part-of-term in which the section is offered. The value entered here must be valid as defined for the term on the Term Control Form - SOATERM. The default is “1”.
SSBSECT_SUBJ_CODE VARCHAR2 16 This field is required in order to add a section. In addition, the combina- tion of Subject, Course Number and Key Block Term must identify a valid course version as maintained in the Catalog Module.
SSBSECT_CRSE_NUMB VARCHAR2 20 This field is used to the determine the course number in the Key Block with a Term and Subject to identify a valid course version from the Catalog Module. If you try to schedule a section for a term restricted on the Schedule Restrictions Form - SCARR
ES, an error occurs.
SSBSECT_SEQ_NUMB VARCHAR2 12 This field identifies the section number of a course. A Section number can only be used once to identify a Subject/Course Number combination in a term, however, multiple sections of a course can share a 0 section number.
SSBSECT_SSTS_CODE VARCHAR2 4 This field maintains the status of a section. The ‘Allow Registration’ switch on the Section Status Validation Form - STVSSTS determines whether the status entered will prevent or allow registration for this section.
SSBSECT_SCHD_CODE VARCHAR2 12 This field identifies the instructional type of the section being scheduled. It is a required field on an add. Use the LIST FIELD VALUES key to display the Schedule Type Validation Form - STVSCHD.
SSBSECT_CAMP_CODE VARCHAR2 12 This field defines the campus on which the section is scheduled. If you attempt to schedule a course for a campus which is restricted on the Course Schedule Restrictions Form - SCASRES, an error will occur.
SSBSECT_CRSE_TITLE VARCHAR2 120 This field will display the title of the course as defined on the Basic Course Information Form - SCACRSE.
SSBSECT_CREDIT_HRS NUMBER 22 This field can be used to restrict a section to a single credit hr. value when the course was defined with variable credit hours. on the Basic Course Information Form - SCACRSE. This value must fall between the variable values.
SSBSECT_BILL_HRS NUMBER 22 This field can be used to restrict a section to a single billing hour value when the course was defined with variable billing hours on the Basic Course Information Form - SCACRSE. This value must fall between the variable values.
SSBSECT_GMOD_CODE VARCHAR2 4 This field can be used to specify one grading mode for this section from the grading mode(s) defined for the course on the Basic Course Information Form - SCACRSE. This field is optional.
SSBSECT_SAPR_CODE VARCHAR2 8 This field can be used to specify the type of special approval a student must have to register. The Special Approval Severity switch on the Term Control Form - SOATERM determines how this is checked at registration.
SSBSECT_SESS_CODE VARCHAR2 4 This field can be used to identify the session in which the section is scheduled. This is an optional field. Use the LIST FIELD VALUES key to display the Session Code Validation Form - STVSESS.
SSBSECT_LINK_IDENT VARCHAR2 8 This field can be used to link other sections of the same course which must be taken concurrently. Enter a code in this field, then enter same code in Link connector field for linked section on Schedule Detail Form - SSADETL.
SSBSECT_PRNT_IND VARCHAR2 4 This field is used to specify whether the section should be printed in the Schedule Report - SSRSECT. “Y” - Yes, print section is the default value.
SSBSECT_GRADABLE_IND VARCHAR2 4 This field is used to specify whether or not the section is gradable. It is a required field and “Y” - Yes, Gradable, is the default value.
SSBSECT_TUIW_IND VARCHAR2 4 This field can be used to specify that this section be exempt from the assessment of tuition and fees as defined on the Registration Fees Process Control Form - SFARGFE (See Field Usage Notes).
SSBSECT_REG_ONEUP NUMBER 22 This field is not displayed on the form (page 0). It displays the count associated with the last student registered for the course section.
SSBSECT_PRIOR_ENRL NUMBER 22 This field is system maintained. When the Section Roll Process, SSRROLL, is used to create section entries based on a previous term222s sections, the Prior enrollment field is set to the enrollment from the prior term.
SSBSECT_PROJ_ENRL NUMBER 22 This field is used to record the anticipated enrollment in the section for the term. It is an optional field which defaults to “0” when a section is added, and it controls no system processing.
SSBSECT_MAX_ENRL NUMBER 22 This field is used to set the maximum enrollment for a section. When the Capacity severity switch is set to ‘W’ or ‘F’ on the Term Control Form - SOATERM, the system issues warnings when enrollment exceeds this number.
SSBSECT_ENRL NUMBER 22 This field is system maintained. It displays a running total of enrollments in the section which have a course status with a ‘Count in Enroll’ flag of ‘Y’ on the Registration Status Code Validation Form - STVRSTS.
SSBSECT_SEATS_AVAIL NUMBER 22 This field is system maintained. It will display a running total of remaining avaialable seats in the section by subtracting the Actual enrollment field from the Maximum enrollment field defined for this section.
SSBSECT_TOT_CREDIT_HRS NUMBER 22 This field is system maintained. It will display a running total of all enrolled credit hours in the section.
SSBSECT_CENSUS_ENRL NUMBER 22 This field is system maintained. It will display the running total of students registered for the section prior to the census date defined for the part of term.
SSBSECT_CENSUS_ENRL_DATE DATE 7 This field is defined in the Census field in the Base Part of Term Block on the Term Control Form - SOATERM, and will default to this field based on the Key Block Term and Part/Term field in the Section Block of this form.
SSBSECT_ACTIVITY_DATE DATE 7 This field specifies the most current date record was created or updated.
SSBSECT_PTRM_START_DATE DATE 7 This field is defined in the Start field in the Base Part of Term Block on the Term Control Form - SOATERM, and will default to this field based on the Key Block Term and Part/Term field in the Section Block of this form.
SSBSECT_PTRM_END_DATE DATE 7 This field is defined in the End field in the Base Part of Term Block on the Term Control Form - SOATERM, and will default to this field based on the Key Block Term and Part/Term field in the Section Block of this form.
SSBSECT_PTRM_WEEKS NUMBER 22 This field is defined in the ‘Wks’ field in the Base Part of Term Block on the Term Control Form - SOATERM, and will default to this field based on the Key Block Term and Part/Term field in the Section Block of this form.
SSBSECT_RESERVED_IND VARCHAR2 4 This field indicates whether reserved seats are defined for the section
SSBSECT_WAIT_CAPACITY NUMBER 22 This field is used to set the maximum waitlist enrollment for a section
SSBSECT_WAIT_COUNT NUMBER 22 This field is system maintained. It displays a running total of enrollments in the section which have course status with a waitlist flag set to Y on the Registration Status Code Validation Form - STVRSTS
SSBSECT_WAIT_AVAIL NUMBER 22 This field is system maintained. It displays a running total of remaining available waitlist seats by subtracting the waitlist actual enrollment from the maximum waitlist enrollment for the section
SSBSECT_LEC_HR NUMBER 22 This field is used to specify the lecture hours specific to this section.
SSBSECT_LAB_HR NUMBER 22 This field is used to specify the lab hours specific to this section.
SSBSECT_OTH_HR NUMBER 22 This field is used to specify the other hours specific to this section. Other hours is defined by the institution.
SSBSECT_CONT_HR NUMBER 22 This field is the column that contains the sum of low lecture, lab and others hours. Contact hours divided by 10 are the continuing education units for a continuing education section. This calculated value is stored in the credit hour field
SSBSECT_ACCT_CODE VARCHAR2 8 Accounting Method Code
SSBSECT_ACCL_CODE VARCHAR2 8 This field can be used to specify the Academic Calendar Type associated with a section.
SSBSECT_CENSUS_2_DATE DATE 7 The census two date for the term and academic calendar year
SSBSECT_ENRL_CUT_OFF_DATE DATE 7 The last date on which students may enroll for the academic calendar type and registration status
SSBSECT_ACAD_CUT_OFF_DATE DATE 7 The last date when student may process a course without it appearing on their academic history information
SSBSECT_DROP_CUT_OFF_DATE DATE 7 The last date on which students may drop a course without assessing a penalty
SSBSECT_CENSUS_2_ENRL NUMBER 22 The census two enrollment
SSBSECT_VOICE_AVAIL VARCHAR2 4 Indicates whether a section is available to Web and Voice Response Telephone Registration. “N” denotes course is not available, “Y” denotes course is available.
SSBSECT_CAPP_PREREQ_TEST_IND VARCHAR2 4 SSBSECT_CAPP_PREREQ_TEST_IND: Deprecated, please see SSBSECT_PREREQ_CHK_METHOD_CDE column comments
SSBSECT_GSCH_NAME VARCHAR2 40 NA
SSBSECT_BEST_OF_COMP NUMBER 22 SECTION BEST OF COMPONENTS: This field indicates the number of child components to be used in subset best of calculations when calculating a section score.
SSBSECT_SUBSET_OF_COMP NUMBER 22 SECTION SUBSET OF COMPONENTS: This field indicates the number of child components to be used in subset calculations when calculating a section score.
SSBSECT_INSM_CODE VARCHAR2 20 Instructional Method Code. The instructional method code assigned to the section
SSBSECT_REG_FROM_DATE DATE 7 Registration From Date. The first date that registration will be open to the learner for this section
SSBSECT_REG_TO_DATE DATE 7 Registration To Date. The last date that registrations will be accepted for this section.
SSBSECT_LEARNER_REGSTART_FDATE DATE 7 Learner Registration Start Date. When registering for the course, the first date that the learner can start taking the course
SSBSECT_LEARNER_REGSTART_TDATE DATE 7 Learner Registration To Date. When registering for the course, the last date that the learner can start taking the course
SSBSECT_DUNT_CODE VARCHAR2 16 Duration Unit Code. The duration unit code assigned to the section
SSBSECT_NUMBER_OF_UNITS NUMBER 22 Duration Number of Units. The number of units the student will be given to complete the course.
SSBSECT_NUMBER_OF_EXTENSIONS NUMBER 22 Number of Extensions. The maximum number of extensions permitted for this section.
SSBSECT_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: Source system that created or updated the row
SSBSECT_USER_ID VARCHAR2 120 USER ID: User who inserted or last update the data
SSBSECT_INTG_CDE VARCHAR2 20 INTEGRATION PARTNER SYSTEM CODE: Code defined on GORINTG that associates with the User Integration Code.
SSBSECT_REFUND_CUT_OFF_DATE DATE 7 LAST DATE FOR GRANTING REFUND: This is the last date a refund is granted when dropping the CRN
SSBSECT_ACYR_CODE VARCHAR2 16 REPORTING YEAR: Reporting Academic Year for this section in apportionment reporting.
SSBSECT_REG_AUTH_ACTIVE_IND VARCHAR2 1 REGISTRATION AUTHORIZATION CODES FOR SECTION INDICATOR: Indicator (Y/N) where null = N. Defaults to “Y”. Allows user to override for this specific CRN the SOBTERM_REG_AUTH_ACTIVE_IND setting when it is “Y” for this term by changing this flag to “N”.
SSBSECT_PREREQ_CHK_METHOD_CDE VARCHAR2 1 SSBSECT_PREREQ_CHK_METHOD_CDE: Indicates type of prerequisite checking. B=Banner Basic, C=CAPP, D=DegreeWorks.
SSBSECT_KEYWORD_INDEX_ID VARCHAR2 120 KEYWORD INDEX ID: Index is updated when the CRN, subject, course number or title are updated to trigger Oracle text index sync.
SSBSECT_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key
SSBSECT_VERSION NUMBER 22 VERSION: Optimistic lock token.
SSBSECT_VPDI_CODE VARCHAR2 24 VPDI CODE: Multi-entity processing code.
SSBSECT_SCORE_OPEN_DATE DATE 7 SCORE OPEN DATE: Score open date.
SSBSECT_SCORE_CUTOFF_DATE DATE 7 SCORE CUTOFF DATE: Score cutoff date.
SSBSECT_REAS_SCORE_OPEN_DATE DATE 7 REAS SCORE OPEN DATE: Reassessment score open date.
SSBSECT_REAS_SCORE_CTOF_DATE DATE 7 REAS SCORE CTOF DATE: Reassessment score cutoff date.
SSBSECT_OVERRIDE_DUR_IND VARCHAR2 4 SCHEDULE DURATION OVERRIDE INDICATOR: Indicates that students are allowed to enter their start and end dates with a non-fixed duration when registering.
SSBSECT_REFUND_CUTOFF_DATE DATE 7 REFUND CUTOFF DATE: The last date the student may receive a refund.
SSBSECT_REG_AUTH_ACTIVE_CDE VARCHAR2 4 SECTION REGISTRATION AUTHORIZATION ACTIVE CODE: Allows user to override for this specific CRN the SOBAUTH_REG_AUTH_ACTIVE_CDE setting. Y - Add authorizations on; N or null - Add authorizations off.
