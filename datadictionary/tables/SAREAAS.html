Below are the column names for SAREAAS.

Columns for SAREAAS
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
SAREAAS_APPLICATION_ID VARCHAR2 40 APPLICATION ID: The unique ID of this application.
SAREAAS_ACTIVITY_DATE DATE 7 ACTIVITY DATE: The date this record was created or updated.
SAREAAS_USER_ID VARCHAR2 120 USER ID: The user ID of the person who inserted or last updated this record.

SAREAAS_VERSION NUMBER 22 VERSION: Optimistic lock token.
SAREAAS_REFERENCE_ID VARCHAR2 40 REFERENCE ID: The candidate’s reference number for their application in the Apply system.
SAREAAS_CANDIDATE_ID VARCHAR2 40 CANDIDATE ID: The candidate’s ID in the Apply system.
SAREAAS_TYPE VARCHAR2 60 TYPE: Type of the object, always ‘application’.
SAREAAS_STATUS VARCHAR2 200 STATUS: The status of this application.
SAREAAS_DERIVED_STATUS VARCHAR2 120 DERIVED STATUS: Banner corresponding status of this application.
SAREAAS_PHASE VARCHAR2 40 PHASE: The phase of this application. In the first phase, ‘apply_1’, the candidate can choose up to 3 courses. If all of those choices are rejected, declined, or withdrawn, the user can go into ‘apply_2’.
SAREAAS_SUBMITTED_ON DATE 7 SUBMITTED ON: Date and Time of submission.
SAREAAS_UPDATED_ON DATE 7 UPDATED ON: Date and Time of last change.
SAREAAS_REJECT_BY_DEFAULT_ON DATE 7 REJECT BY DEFAULT ON: Time when the application is due to be rejected by default.
SAREAAS_PERSONAL_STATEMENT CLOB 4000 PERSONAL STATEMENT: The candidate’s personal statement, combined from the ‘Becoming a Teacher’ and ‘Subject Knowledge’ fields in the application form.
SAREAAS_INTERVIEW_PREFERENCES CLOB 4000 INTERVIEW PREFERENCES: The candidate’s interview preferences.
SAREAAS_FURTHER_INFORMATION CLOB 4000 FURTHER INFORMATION: Other personal or professional issues relevant to the application which are not covered in the form.
SAREAAS_FIRST_NAME VARCHAR2 240 FIRST NAME: The candidate’s first name.
SAREAAS_LAST_NAME VARCHAR2 240 LAST NAME: The candidate’s last name.
SAREAAS_DATE_OF_BIRTH DATE 7 DATE OF BIRTH: The candidate’s date of birth.
SAREAAS_NATIONALITY VARCHAR2 120 NATIONALITY: The candidate’s nationality.
SAREAAS_DERIVED_NATIONALITY VARCHAR2 120 DERIVED NATIONALITY: Banner corresponding nationality of the candidate.
SAREAAS_RESIDENCY_STATUS VARCHAR2 1024 RESIDENCY STATUS: The candidate’s residency status.
SAREAAS_ENGLISH_MAIN_LANG VARCHAR2 4 ENGLISH MAIN LANG: Does this candidate have English as a main language?.
SAREAAS_ENGLISH_LANGUAGE_QUAL CLOB 4000 ENGLISH LANGUAGE QUALIFICATION: English language qualifications details of the candidate.
SAREAAS_OTHER_LANGUAGE CLOB 4000 OTHER LANGUAGE: Details of the candidate’s fluency in other languages.
SAREAAS_DISABILITY_DISCLOSURE CLOB 4000 DISABILITY DISCLOSURE: Voluntary disclosure of disabliity or SEN so providers can provide appropriate support.

SAREAAS_ADDRESS_LINE3 VARCHAR2 200 ADDRESS LINE3: The candidate’s address line 3.
SAREAAS_ADDRESS_LINE4 VARCHAR2 200 ADDRESS LINE4: The candidate’s address line 4.
SAREAAS_POSTAL_CDE VARCHAR2 32 POSTAL CDE: The candidate’s postcode.
SAREAAS_COUNTRY VARCHAR2 12 COUNTRY: The candidate’s country.
SAREAAS_NATN_CODE VARCHAR2 20 NATN CODE: Banner corresponding country code of the candidate.
SAREAAS_EMAIL VARCHAR2 400 EMAIL: The candidate’s email address.
SAREAAS_PHONE VARCHAR2 200 PHONE: The candidate’s phone number.
SAREAAS_ACADEMIC_YEAR NUMBER 22 ACADEMIC YEAR: Academic Year.
SAREAAS_PROVIDER_CDE VARCHAR2 12 PROVIDER CDE: The provider’s code.
SAREAAS_SBGI_CODE VARCHAR2 80 SBGI CODE: Banner corresponding provider code of the course.
SAREAAS_COURSE_CDE VARCHAR2 16 COURSE CDE: The course’s code.
SAREAAS_SITE_CDE VARCHAR2 20 SITE CDE: The site’s code.
SAREAAS_CAMP_CODE VARCHAR2 12 CAMP CODE: Banner corresponding site code of the course.
SAREAAS_STUDY_MODE VARCHAR2 40 STUDY MODE: Mode of Study.
SAREAAS_DERIVED_STUDY_MODE VARCHAR2 120 STUDY MODE: Banner corresponding mode of study of the course.
SAREAAS_GENDER VARCHAR2 8 GENDER: The candidate’s gender.
SAREAAS_DERIVED_GENDER VARCHAR2 120 DERIVED GENDER: Banner corresponding gender of the candidate.
SAREAAS_DISABILITY VARCHAR2 200 DISABILITY: The candidate’s disability.
SAREAAS_DERIVED_DISABILITY VARCHAR2 800 DERIVED DISABILITY: Banner corresponding disability of the candidate.
SAREAAS_ETHNICITY VARCHAR2 12 ETHNICITY: The candidate’s ethnicity.
SAREAAS_ETHN_CODE VARCHAR2 8 ETHN CODE: Banner corresponding ethnicity code of the candidate.
SAREAAS_WITHDRAWAL_DATE DATE 7 WITHDRAWAL DATE: Date of the withdrawal.
SAREAAS_REJECTION_REASON CLOB 4000 REJECTION REASON: The reason for rejection or offer withdrawal.
SAREAAS_REJECTION_DATE DATE 7 REJECTION DATE: Date of rejection.
SAREAAS_SAFEGUARDING_STATUS VARCHAR2 400 SAFEGUARDING STATUS: Status of candidate’s response to the safeguarding issues declaration.
SAREAAS_SAFEGUARDING_DETL_URL VARCHAR2 2000 SAFEGUARDING DETL URL: URL to Apply system where safeguarding issues disclosed by the candidate can be access by users with permissions to view safeguarding information.
SAREAAS_PROCESS_IND VARCHAR2 4 PROCESS IND: Denotes Whether Application has been Processed.
SAREAAS_TERM_CODE VARCHAR2 24 TERM CODE: Initial Term Associated with the Base Curriculum Rule.
SAREAAS_CURRICULUM_RULE NUMBER 22 CURRICULUM RULE: Base Curriculum Rule Reference.
SAREAAS_FOS_CURRICULUM_RULE NUMBER 22 FIELD OF STUDY CURRICULUM RULE: Curriculum rule from the curriculum table.
SAREAAS_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: Source system that generated the data.
SAREAAS_VPDI_CODE VARCHAR2 24 VPDI CODE: VPDI CODE: Multi-entity processing code.
SAREAAS_APPL_SEQNO NUMBER 22 APPLICATION SEQUENCE NUMBER: Staging Application Sequence Number.
SAREAAS_DOMICILE VARCHAR2 8 CANDIDATE DOMICILE: The candidate’s domicile, extracted from their address.
SAREAAS_RESIDENCY_STATUS_CODE VARCHAR2 4 RESIDENCY STATUS CODE: Single alphabetical character code for the candidate’s residency status indicating their right to work and study in the country.
SAREAAS_FEE_PAYER_STATUS VARCHAR2 8 FEE PAYER STATUS: Provisional fee payer status based on a candidate’s nationality, residency status and domicile.

SAREAAS_OFFER_MADE_AT_DATE DATE 7 OFFER AT: Date and time the offer was given.
SAREAAS_OFFER_ACCEPTED_DATE DATE 7 OFFER ACCEPTED AT: Date and time the offer was accepted.
SAREAAS_OFFER_DECLINED_DATE DATE 7 OFFER DECLINED AT: Date and time the offer was declined.
SAREAAS_OFFER_YEAR VARCHAR2 16 OFFER YEAR: The offered course’s recruitment cycle year.
SAREAAS_OFFER_PROVIDER_CODE VARCHAR2 12 OFFER PROVIDER CODE: The offered course’s institution code.
SAREAAS_OFFER_SBGI_DERIVED VARCHAR2 80 DERIVED PROVIDER CODE: The Source/Background institution code equivalent Banner value for Institution.
SAREAAS_OFFER_SITE_CODE VARCHAR2 20 OFFER SITE CODE: The offered course’s campus code.
SAREAAS_OFFER_CAMPUS_DERIVED VARCHAR2 20 DERIVED SITE CODE: The STVCAMP equivalent Banner value for Campus.
SAREAAS_OFFER_COURSE VARCHAR2 16 OFFER COURSE: The offered course code.

SAREAAS_APPLIED_COURSE_START DATE 7 APPLIED COURSE START AT: Applied course’s start date.
SAREAAS_RECRUITED_DATE DATE 7 RECRUITED DATE: Date when the candidate met their conditions, receiving a firm place on the course.
SAREAAS_HESA_OTHER_DISABILITY CLOB 4000 HESA OTHERS: The candidate’s description of their disability, if they selected “Other” and entered a value.
SAREAAS_HESA_OTHER_ETHNICITY CLOB 4000 ETHNICITY OTHERS: The candidate’s description of their ethnicity, if they selected “Other” and entered a value.
SAREAAS_OFFER_CURRICULUM_RULE NUMBER 22 CURRICULA RULE: Base Curriculum Rule for offered course.
SAREAAS_OFFER_MAJOR_RULE NUMBER 22 FIELD OF STUDY CURRICULUM RULE: Major rule attributed to the curriculum rule.
SAREAAS_DERIVED_DOMICILE VARCHAR2 8 DERIVED DOMICILE: The Banner equivalent representing HESA Domicile values.
SAREAAS_APPL_CHANGE_DETAILS VARCHAR2 400 APPLICATION CHANGE DETAILS: Details related to change in application.
SAREAAS_STATUS_BEFORE_DEFERRAL VARCHAR2 120 STATUS BEFORE DEFERRAL: Application status before the offer deferral.
SAREAAS_OFFER_DEFERRED_DATE DATE 7 OFFER DEFERRED DATE: Date when this offer application was deferred.
SAREAAS_DEFERRED_YEAR VARCHAR2 16 DEFERRED YEAR: The recruitment cycle year a deferred application can be confirmed.
SAREAAS_WITHDRAWN_DECLINED_IND VARCHAR2 4 WITHDRAWN OR DECLINED INDICATOR: Indicator for when application is withdrawn or offer declined at candidate?s request.
