SVRORAT

Below are the column names for SVRORAT.

Columns for SVRORAT
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
SVRORAT_PIDM NUMBER 22 PIDM: PIDM attached to the OCAS applicant
SVRORAT_OCAS_APPL_NUM VARCHAR2 36 OCAS APPL NUM: OCAS applicant number
SVRORAT_OPRG_CODE VARCHAR2 32 OCAS PROGRAM CODE: OCAS program code
SVRORAT_TERM_CODE VARCHAR2 24 TERM CODE: Term code in which the program is being offered
SVRORAT_SEMESTER NUMBER 22 SEMESTER: Semester for which the program is offered
SVRORAT_OCMP_CODE VARCHAR2 16 OCMP CODE: OCAS campus code
SVRORAT_START_DATE NUMBER 22 START DATE: Start date. This is starting year and month of program (YYMM). Same as SVRORAT_START_DATE. It takes the earliest start-date when collision exists for the same term-semester.
SVRORAT_FULL_PART_TIME VARCHAR2 4 FULL OR PART TIME INDICATOR: Values can be: F-Full time (this has the highest priority when assigning offers), P-Part time indicator.
SVRORAT_ECD_IND VARCHAR2 4 EQUAL CONSIDERATION DATE INDICATOR: To indicate whether the date application received (SVRORAT_DATE_PROG_RCVD) of the applicant was received before or after the equal consideration date (SVROTCT_EQ_CONS_DATE)
which is typically FEB-01 of the OCAS year. Values can be: 1-Equal consideration, 2-Not equal consideration.
SVRORAT_QUEUE_PRIORITY VARCHAR2 4 QUEUE PRIORITY: This is used to mark the order in which the applicant will be processed depending on the queue type that applicant had assigned in SVROCCC when SVPORNK started.
Values can be 1-When applicant had an O (offer), 2 When applicant had a W (waitlist), 3- When applicant had an R (refusal), NULL- When applicant had no queue assigned yet.
SVRORAT_SCORE_1 NUMBER 22 SCORE: 1 used by the ranking process when sorting the applicants population for getting the ranks. Values can be: SVRORAT_NEW_SCORE
when SVRORAT_ECD_IND is 1(Pre-ECD, this is application was received BEFORE the equal consideration date). ZERO when SVRORAT_ECD_IND is 2 (Post ECD, this is application was received AFTER the equal consideration date).
SVRORAT_DATE_PROG_RCVD DATE 7 DATE PROG RCVD: Date when the application for the program has been received. This can be the date first time program was received, or when program was re-activated, etc. This field has the same value as SVRORAT_DATE_PROG_RCVD field.
SVRORAT_SCORE_2 NUMBER 22 SCORE 2: Used by the ranking process when sorting the applicants population for getting the ranks. Values can be: ZERO when SVRORAT_ECD_IND is 1 (Pre-ECD, this is application was received BEFORE the equal consideration date).
SVRORAT_NEW_SCORE when SVRORAT_ECD_IND is 2 (Post-ECD, this is application was received AFTER the equal consideration date).
SVRORAT_PROG_CHOICE_SEQ_NO NUMBER 22 PROGRAM CHOICE SEQUENCE NUMBER: The reported program choice sequence number. Values: 1..5 - Offer to original program choice, 6 - Alternate offer.
SVRORAT_ACTIVITY_DATE DATE 7 ACTIVITY DATE: The date that information in this record was entered or last updated.
SVRORAT_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key
SVRORAT_VERSION NUMBER 22 VERSION: Optimistic lock token.
SVRORAT_USER_ID VARCHAR2 120 USER ID: The user ID of the person who inserted or last updated this record.
SVRORAT_NEW_ELIG_MET_IND VARCHAR2 4 NEW ELIGIBILITY MET INDICATOR: Indicates if most recent eligibility was met or not. Values are: Y-yes, N-not met. Value comes from SVROCCC_NEW_ELIG_MET_IND.
SVRORAT_OLD_ELIG_MET_IND VARCHAR2 4 OLD ELIGIBILITY MET INDICATOR: Indicates if prior eligibility was met or not. Values are: Y-yes, N-not met. Value comes from SVROCCC_OLD_ELIG_MET_IND.
SVRORAT_WL_RANK NUMBER 22 WL RANK: Waitlist rank that applicant had in the waitlist queue when ranking (SVPORNK) started. This field takes the same value as SVROWLQ_CURR_RANK.
This will have a value only for applicants that had a W in the SVROCCC_QUEUE_TYPE when ranking started.
SVRORAT_OF_RANK NUMBER 22 OFFER RANK: Offer rank that applicant had in the offer queue when ranking (SVPORNK) started. This field takes the same value as SVROOFR_RANK.
This will have a value only for applicants that had an O in the SVROCCC_QUEUE_TYPE when ranking started.
SVRORAT_RANK_DATE DATE 7 RANK DATE: Rank date. This is date when rank was calculated.
SVRORAT_RANDOM_NUM NUMBER 22 RANDOM NUM: Random number, it is the number used for breaking ties between applicants with the same score when ranking process was run.
SVRORAT_QUEUE_TYPE VARCHAR2 4 QUEUE TYPE: It is the queue to which the applicant was assigned by the ranking process or the queue that applicant had assigned manually before running ranking process. Values can be: O- offer queue, W- waitlist queue, R- refusal queue.
SVRORAT_QUEUE_MODE VARCHAR2 4 QUEUE MODE: The mode in which the applicant was assigned to the queue. Values can be: M- manual (when queue type is O this indicates that the assignment to the queue was Early offer),
B- bulk (assignment to the queue was through a bulk run, this means the ranking process).
SVRORAT_OOGR_CODE VARCHAR2 16 OFFER GROUP CODE: Offer Group code to which the applicant is associated depending on the program. This offer group code is determined when evaluating the applicant data against the offer group rules (defined in SVROOGR)
for the groups associated to the program (defined in SVROPOR)
SVRORAT_QUEUE_STATUS VARCHAR2 4 QUEUE STATUS: It is the status in which the applicant is regarding the queue. This status can be trial or real depending on the way the ranking process was run (parameter trial = Y or N). Values can be: R-Real (when applicant
