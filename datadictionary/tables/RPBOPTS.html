RPBOPTS

Below are the column names for RPBOPTS.

Columns for RPBOPTS
COLUMN_NAME DATA_TYPE DATA_LENGTH COMMENTS
RPBOPTS_AIDY_CODE VARCHAR2 16 AID YEAR CODE: The aid year to be associated with information in this record. ,
RPBOPTS_EST_ENROLL_PELL_IND VARCHAR2 4 ESTIMATED ENROLLMENT INDICATOR: This field determines whether the applicant’s estimated enrollment is to be used during the Awarding Process. Field defaults to value of (Y)es.
RPBOPTS_DEFAULT_OPTION_IND VARCHAR2 4 DEFAULT ESTIMATED ENROLLMENT: The value in this field is used if the ‘Use estimated enrollment’ indicator is not checked. Also used if ‘Use estimated enrollment’ indicator is checked but the RCRAPP1 expected enrollment field is null.
RPBOPTS_INTERFACE_EXEMPT_IND VARCHAR2 4 INTERFACE EXEMPTIONS INDICATOR: This field indicates whether the institution wishes to interface exemptions from the banner student system.
RPBOPTS_INTERFACE_3PARTY_IND VARCHAR2 4 INTERFACE THIRD PARTY CONTRACTS: This field indicates whether the institution wishes to interface third party contracts from the banner student system.
RPBOPTS_ACTIVITY_DATE DATE 7 ACTIVITY DATE: The date that information in this record was entered or last updated.
RPBOPTS_PCKG_USING_TFC_IND VARCHAR2 4 PACKAGE USING ESTIMATED TFC INDICATOR: A packaging option which allows the institution to package using estimated TFC.
RPBOPTS_MASS_ACCEPT_IND VARCHAR2 4 MASS ACCEPTANCE INDICATOR: A packaging option which allows the institution to allow award mass acceptance.
RPBOPTS_DISB_ACT_ENROLL_IND VARCHAR2 4 DISBURSE USING ACTUAL ENROLLMENT INDICATOR: Indicates whether the institution chooses to disburse funds based on actual enrollment.
RPBOPTS_OFFER_EXP_DAYS VARCHAR2 12 OFFER EXPIRATION DAYS: A packaging option which allows the institution to determine the number of days that a financial aid offer is valid prior to expiration. Identifies the number of days to be added to the offer date.
RPBOPTS_TRST_CODE VARCHAR2 4 TRACKING REQUIREMENT STATUS CODE: Allows the institution to define the tracking requirement status code which will be posted to the applicants tracking record as a fund is packaged.
RPBOPTS_ALWAYS_USE_EST_IND VARCHAR2 4 ALWAYS USE ESTIMATED INDICATOR: This field indicates whether estimates should be used for exemptions and third party contracts.
RPBOPTS_ASSUME_FULL_TIME_IND VARCHAR2 4 ASSUME FULL-TIME INDICATOR: Indicates whether the institution wishes to assume full-time enrollment when packaging exemptions and contracts.
RPBOPTS_3QUARTER_TIME_PCT NUMBER 22 THREE QUARTER TIME PERCENT: Represents the percentage of the contract or exemption to use if the student is enrolled on a three-quarter time basis.
RPBOPTS_HALF_TIME_PCT NUMBER 22 HALF-TIME PERCENT: Indicates the percentage of the contract or exemption which will be considered in packaging if the student is enrolled on a half time basis.
RPBOPTS_LESS_HALF_TIME_PCT NUMBER 22 LESS THAN HALF TIME PERCENT: Indicates the percentage of the contract or exemption to consider in packaging if the student is enrolled on a less than half time basis.
RPBOPTS_USE_AR_IND VARCHAR2 4 USE AR INDICATOR: This disbursement option controls if payments can be made to the student account if the charges haven’t been accepted.
RPBOPTS_ADDL_STFD_ELIG_DEF_IND VARCHAR2 4 ADDITIONAL STAFFORD ELIGIBILITY INDICATOR DEFAULT: Default indicator for additional stafford eligibility.
RPBOPTS_AWRD_HIST_SRC_IND VARCHAR2 4 AWARD HISTORY SOURCE INDICATOR: Indicates which source of award history to use during award packaging and disbursement validation. B or blank - Banner, N - NSLDS.
RPBOPTS_PCKG_CFLAGS_IND VARCHAR2 4 PACKAGE C-FLAGS INDICATOR: Indicates whether Packaging should occur if SAR C-Flags exist. Y or blank - Package even if C-Flags exist. N - Do not package if C-Flags exist.
RPBOPTS_DISB_CFLAGS_IND VARCHAR2 4 DISBURSE C-FLAGS INDICATOR: Indicates whether Disbursement should occur if SAR C-Flags exist. Y or blank - Disburse even if C-Flags exist. N - Do not disburse if C-Flags exist.
RPBOPTS_PELL_DISB_IND VARCHAR2 4 GRANT DISBURSEMENT INDICATOR: Indicates if disbursement amount, award amount or a zero amount should be used for ACG, PELL, SMART and TEACH disbursement when award and disbursement amounts are not equal.
RPBOPTS_PELL_LT_HALF_COA NUMBER 22 PELL LESS THAN HALF TIME COA: Default PELL Cost of Attendance for students who are enrolled for less than half time.
RPBOPTS_ALLOW_MEMO_IND VARCHAR2 4 ALLOW MEMO INDICATOR: Indicates whether to allow memoing when disbursement has been backed out, and to allow memoing of future scheduled disbursements when previously paid disbursements exist.
RPBOPTS_PELL_EFC_DISB_IND VARCHAR2 4 PELL PAYMENT CELL EFC INDICATOR: This field indicates whether to disburse Pell when System EFC and SAR EFC are not equal but are within the same PELL payment cell.
RPBOPTS_PELL_NSLDS_IND VARCHAR2 4 PELL NSLDS INDICATOR: A value of ‘Y’ indicates that NSLDS Pell award information will be used in the calculation of Pell awards. The Pell award received at this school will be reduced by any Pell award amounts received at other schools.
RPBOPTS_ZERO_PELL_AWRD_DEL_IND VARCHAR2 4 PELL DELETE ZERO AWARD: A ‘Y’ indicates that Pell awards will be physically deleted from the database if the award is reduced to 0 by the Pell calculation, if no locks, originations, memo, authorization, or paid amounts exist.
RPBOPTS_USER_ID VARCHAR2 30 USER ID: The user ID of the person who inserted or last updated this record.
RPBOPTS_CROSSOVER_CUTOFF_DATE DATE 7 PELL CROSSOVER CUTOFF DATE: The last date on which Pell summer crossover awards will be automatically calculated by the Pell process.
RPBOPTS_SURROGATE_ID NUMBER 22 SURROGATE ID: Immutable unique key
RPBOPTS_VERSION NUMBER 22 VERSION: Optimistic lock token.
RPBOPTS_DATA_ORIGIN VARCHAR2 120 DATA ORIGIN: Source system that created or updated the data.
RPBOPTS_VPDI_CODE VARCHAR2 24 VPDI CODE: Multi-entity processing code.
